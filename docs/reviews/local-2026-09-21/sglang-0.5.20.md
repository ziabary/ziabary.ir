# SGLang 0.5.20 ــ بازبینی ۳۰ شهریور ۱۴۰۵

نسخهٔ 0.5.20 به دادهٔ مرجع و جدول نرم‌افزارها در فارسی، انگلیسی و اسپانیایی اضافه شد. ردیف `software-release:sglang-v0-5-19` و تمام ارجاعات تاریخی آن بدون تغییر باقی ماندند. تاریخ انتشار ردیف جدید ۱۸ سپتامبر ۲۰۲۶ و تاریخ بازبینی آن ۲۱ سپتامبر است.

منابع بررسی‌شده:

- [انتشار 0.5.20](https://github.com/sgl-project/sglang/releases/tag/v0.5.20)
- [توقف انتشار بسته‌ها و ایمیج‌های CUDA 12](https://github.com/sgl-project/sglang/pull/38404): آخرین مسیر CUDA 12 نسخهٔ 0.5.19 است؛ ایمیج‌های قبلاً منتشرشده حذف نشده‌اند.
- [شرایط ذخیره‌سازی Responses](https://github.com/sgl-project/sglang/pull/39122): بازیابی، زنجیره‌سازی با previous_response_id و درخواست پس‌زمینه به --enable-response-store نیاز دارند؛ فعال‌کردن آن در استقرار PD مجاز نیست. تولید پاسخ عادی و streaming با ذخیره‌سازی خاموش کار می‌کنند.
- [README همان نسخه](https://github.com/sgl-project/sglang/blob/v0.5.20/README.md) و [مجوز همان نسخه](https://github.com/sgl-project/sglang/blob/v0.5.20/LICENSE).

توضیح هر ردیف اکنون با نام نرم‌افزار **و نسخه** تطبیق داده می‌شود؛ بنابراین خلاصهٔ قدیمی 0.5.19 روی ردیف 0.5.20 قرار نمی‌گیرد. منابع جدید به خود ردیف و ادعای API متصل‌اند. شناسهٔ ردیف جدید `software-release:sglang-v0-5-20` است. چهار قابلیت عمومی runtime از README همان نسخه ثبت شدند؛ نتایج عملکرد قبلی به نسخهٔ جدید منتقل نشدند.

فیلتر نسخه هر دو ردیف را به‌صورت مستقل نگه می‌دارد. ویزارد از راهنمای اجرای هر مدل، نام موتور و بستهٔ مدل را انتخاب می‌کند و نسخهٔ SGLang یا CUDA را خودکار ارتقا نمی‌دهد. جست‌وجوی اولین انتشار در مؤلفهٔ ویزارد صرفاً برای لینک مجوز نرم‌افزار است؛ منطق انتخاب محیط اجرا نیست. در نتیجه نسخهٔ جدید به‌عنوان سازگار با تمام محیط‌های موجود اعلام نشده است.

مقایسهٔ JSON قبل و بعد تأیید کرد که benchmarkRuns، publishedEvaluations، executionFeasibility، hardwareConfigurations، deploymentConfigurations، engines و servingStacks تغییری نکرده‌اند. تاریخ کلی بازبینی داده به ۲۱ سپتامبر رسید؛ تاریخ نتایج و منابع قدیمی ثابت ماند.

بررسی‌ها: `npm run verify:llm` موفق؛ `npm run check` صفر خطا و هشدار؛ `npm run build` موفق؛ ۲۳۱ آزمون موفق. آزمون جدید تفکیک نسخه، ترجمهٔ شرایط نصب و API و حفظ ردیف قدیمی را بررسی می‌کند. آزمون مرورگر، جزئیات و لینک منابع هر سه زبان را نیز کنترل می‌کند.

آزمون نصب SGLang یا اجرای GPU انجام نشده است. این تغییر فعلاً محلی است و کامیت، پوش یا دیپلوی نشده است.
