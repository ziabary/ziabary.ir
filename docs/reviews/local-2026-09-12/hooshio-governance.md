# افزودن گزارش هوشیو به بازتاب‌ها

گزارش «کلاف سردرگم حکمرانی هوش مصنوعی در ایران؛ از موازی‌کاری ساختاری تا بیم سلب فرصت در مسابقه جهانی» با خلاصهٔ اختصاصی ۱۶۱ کلمه‌ای، تصویر اصلی ناشر و لینک مطالعهٔ خبر به `src/lib/news.ts` اضافه شد.

- [منبع هوشیو](https://hooshio.com/the-tangled-web-of-ai-governance-in-iran-from-structural-duplication-to-fear-of-missing-out-in-the-global-race/)
- تاریخ درج‌شده در منبع: ۱۹ شهریور ۱۴۰۵؛ معادل میلادی: `2026-09-10`.
- تصویر اصلی: `static/images/news/hooshio-92097.jpg` با ابعاد ۱۲۸۰ × ۸۵۳، همراه با نسخه‌های واکنش‌گرا.
- مسیر بازبینی: <http://localhost:5173/media/#published>؛ گزارش در ابتدای فهرست و فیلتر «گزارش» قرار دارد.
- فرمان اجرای محیط توسعه: `npm run dev -- --host 127.0.0.1`.
- پیش‌نمایش خروجی ساخته‌شده: `npm run preview:local`؛ <http://127.0.0.1:4186/media/#published>.

`npm run check` بدون خطا و هشدار گذشت. `npm run build` موفق بود و ۱۶۳ نشانی نقشهٔ سایت و ۱۷۲ بلوک JSON-LD اعتبارسنجی شدند. بررسی خروجی ایستا، تصویر، تاریخ، لینک ناشر، باز و بسته‌شدن خلاصه و فیلترهای گزارش/یادداشت در مرورگر با عرض‌های ۱۴۴۰ و ۳۹۰ پیکسل موفق بود؛ خطای اجرایی ثبت نشد. بررسی قدیمی لینک‌های یادداشت زاویه نیز به‌روزرسانی شد تا به اول‌بودن آن در فهرست وابسته نباشد.
