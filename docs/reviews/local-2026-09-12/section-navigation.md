# دنبال‌کردن زیربخش‌ها در فهرست مطالب

منوی مقاله و مجموعه‌های فنی اکنون تیترهای سطح دوم و سوم را هنگام پیمایش دنبال می‌کند. مسیر مقاله و بخش والد مشخص می‌ماند؛ فقط تیتر جاری `aria-current="location"` و پس‌زمینهٔ فعال می‌گیرد. منوی بلند برای نمایش همان پیوند، درون خودش پیمایش می‌شود. پیمایش متن، آدرس یا تاریخچهٔ مرورگر را تغییر نمی‌دهد.

تشخیص بخش جاری از ترتیب واقعی تیترهای قابل‌مشاهده و موقعیت آن‌ها نسبت به سربرگ استفاده می‌کند. تیترهای فصل بسته کنار گذاشته می‌شوند؛ بازکردن فصل، تغییر اندازه، بارگذاری تصویر و جابه‌جایی بین مقاله‌ها موقعیت را به‌روز می‌کند. لینک مستقیم و بازکردن دوبارهٔ همان فصل همچنان کار می‌کند. نسخه‌های انگلیسی و اسپانیایی GPU نیز فهرست زیربخش دارند.

فرمان اجرا: `npm run dev -- --host 127.0.0.1`.

اعتبارسنجی:

- `npm run check`: بدون خطا و هشدار.
- `npm run build`: موفق؛ نقشهٔ سایت و داده‌های ساختاریافته معتبر.
- `npm test`: هر ۴۸ آزمون موفق.
- `npm run verify:local`: ۱۷۳ صفحه، بدون خطای پیوند و شناسهٔ مقصد.
- `node scripts/review-section-navigation.mjs`: هر ۱۰ بررسی مرورگر موفق، بدون خطای اجرایی؛ شامل پیمایش رفت‌وبرگشت، تیترهای H3، سه زبان، لینک مستقیم، تغییر مقاله، بسته‌شدن فصل، بازکردن همان مقصد و منوی موبایل.
