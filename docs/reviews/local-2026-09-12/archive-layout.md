# انتخاب چیدمان آرشیو

بالای آرشیو فارسی، انگلیسی و اسپانیایی یک انتخاب‌گر برای نمایش سه‌ستونی با کارت‌های سابق یا فهرست تک‌ستونی قرار گرفت. حالت پیش‌فرض سه‌ستونی است و انتخاب خواننده در مرورگر حفظ می‌شود. جست‌وجو، موضوع، دسته، ترتیب نوشته‌ها و صفحهٔ فعلی با تغییر نمایش حفظ می‌شوند. نمایش کارتی در تبلت دو ستون و در موبایل یک ستون دارد.

- اجرا: `npm run dev -- --host localhost --port 5173`
- بازبینی: [فارسی](http://localhost:5173/articles/)، [انگلیسی](http://localhost:5173/en/articles/)، [اسپانیایی](http://localhost:5173/es/articles/)
- خروجی ایستا: `npm run build` و `npm run preview:local`، سپس [آرشیو](http://127.0.0.1:4186/articles/)
- تصاویر: [سه‌ستونی](archive-grid-fa-1440.png)، [تک‌ستونی](archive-list-fa-1440.png)، [حالت تیره](archive-grid-fa-1440-dark.png)، [موبایل کارتی](archive-grid-fa-390.png)، [موبایل فهرستی](archive-list-fa-390.png)

`check` بدون خطا و هشدار، `build` موفق، هر ۴۸ آزمون موفق و بررسی ۱۷۳ صفحه بدون خطای پیوند یا شناسه انجام شد. مرورگر هر دو نمایش را در هر سه زبان، حفظ انتخاب پس از بارگذاری و صفحه‌بندی، حفظ جست‌وجو و دسته، حالت تیره و عرض‌های ۱۴۴۰، ۷۶۸ و ۳۹۰ آزمود. انتخاب‌گر با غیرفعال‌بودن دسترسی به ذخیره‌سازی مرورگر نیز قابل استفاده بود. خطای اجرا و بیرون‌زدگی افقی مشاهده نشد.

گزارش‌ها: [check](archive-layout-check.log)، [build](archive-layout-build.log)، [آزمون‌ها](archive-layout-tests.log)، [پیوندها](archive-layout-audit.log)، [مرورگر](archive-layout-check.json). انتشار عمومی انجام نشده است.
