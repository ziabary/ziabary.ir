بررسی چیدمان چهار محور صفحهٔ اندیشه — ۱۲ سپتامبر ۲۰۲۶

مسیر بازبینی: http://127.0.0.1:4186/thought/
فرمان اجرای نسخهٔ ساخته‌شده: npm run preview:local

CSS قبلی همچنان سه ستون داشت و محور چهارم در دسکتاپ تنها به ردیف بعد می‌رفت. تغییر این مرحله فقط در CSS صفحهٔ فارسی است؛ متن و تغییرات تازهٔ کاربر حفظ شده‌اند.

- بالاتر از ۹۸۰ پیکسل: چهار ستون مساوی در یک ردیف.
- از ۶۸۱ تا ۹۸۰ پیکسل: دو ستون و دو ردیف؛ جداکننده‌ها متناسب با هر ردیف.
- تا ۶۸۰ پیکسل: همان چهار ردیف تک‌ستونی قبلی با جداکننده‌های افقی.

۲۴ حالت در مرورگر روی خروجی استاتیک بررسی شد: عرض‌های ۳۲۰، ۳۶۰، ۳۹۰، ۴۸۰، ۶۸۰، ۶۸۱، ۷۶۸، ۹۸۰، ۹۸۱، ۱۰۲۴، ۱۴۴۰ و ۱۹۲۰ پیکسل، هر کدام در پوستهٔ روشن و تیره. تعداد ستون‌ها، ترتیب چهار محور، محل جداکننده‌ها و نبود بیرون‌زدگی متن و کادرهای این بخش در همهٔ حالت‌ها تأیید شد. خطای اجرای جاوااسکریپت مشاهده نشد.

در عرض‌های ۳۲۰ و ۳۶۰ پیکسل، هدر مشترک سایت از قبل بیرون‌زدگی افقی دارد؛ گروه nav-tools و انتخاب زبان در سمت چپ جا کم می‌آورند. این مورد در تصاویر و اندازه‌گیری‌های قبل و بعد دیده می‌شود و ناشی از بخش چهار محور نیست. این بررسی آن را برطرف نمی‌کند و نتیجهٔ بدون بیرون‌زدگی صرفاً دربارهٔ خود بخش چهار محور است.

npm run check: صفر خطا و صفر هشدار.
npm run build: موفق؛ نقشهٔ سایت با ۱۶۳ مسیر و ۱۷۲ بلوک JSON-LD اعتبارسنجی شد.
npm run verify:local: ۱۷۳ صفحه، صفر خطا و صفر پیوند داخلی نامعتبر.

تصاویر thought-axes-before-* و thought-axes-after-* و اندازه‌گیری‌های thought-axes-before.json و thought-axes-after.json در همین پوشه قرار دارند. نسخهٔ نهایی به‌صورت محلی آماده است.
