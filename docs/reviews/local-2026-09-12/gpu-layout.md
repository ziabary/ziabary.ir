# اصلاح چیدمان راهنمای GPU

به درخواست صاحب سایت، قاب دسکتاپ عنوان، ورودی، جدول GPU و جدول سرور به اندازه‌ها و تراز نسخهٔ قبلی برگشت. تصویر ورودی و بخش «از کجا شروع کنیم؟» دوباره نسبت ۳ به ۲ دارند و فهرست در سمت راست قرار دارد.

فصل‌های جمع‌شونده، مطالعهٔ پیوسته، منوی فعال و بازشدن فصل از پیوند زیربخش حفظ شدند. فصل‌هایی که با تیتر سطح سوم آغاز می‌شوند هم اکنون زیربخش‌هایشان را در منو نشان می‌دهند. چیدمان موبایل و تبلت با منوی جمع‌شونده حفظ شده است.

- اجرا: `npm run dev -- --host localhost --port 5173`
- [صفحهٔ توسعه](http://localhost:5173/guides/gpu-selection/)
- [خروجی ایستای محلی](http://127.0.0.1:4186/guides/gpu-selection/)، با `npm run build` و `npm run preview:local`
- تصاویر: [ورودی دسکتاپ](gpu-layout-after-1440.png)، [جدول](gpu-layout-table-1440.png)، [فصل و زیربخش‌های منو](gpu-layout-open-chapter-1440.png)، [موبایل](gpu-layout-after-390.png)
- مرجع چیدمان قبلی: [تصویر ثبت‌شدهٔ ۹ سپتامبر](../local-2026-09-09/before/gpu-1440.png)

`check` بدون خطا و هشدار، `build` موفق با ۱۶۳ مسیر در sitemap، هر ۴۸ آزمون موفق، و بررسی ۱۷۳ صفحه بدون خطای پیوند و شناسه انجام شد. عرض‌های ۳۹۰، ۷۶۸، ۱۲۸۰، ۱۴۴۰ و ۱۹۲۰ در مرورگر بررسی شدند؛ بیرون‌زدگی افقی صفحه یا خطای اجرا وجود نداشت. باز و بسته‌کردن فصل، مطالعهٔ پیوسته، منوی زیربخش، ورود مستقیم با نشانی زیربخش و منوی موبایل آزموده شدند.

گزارش‌ها: [check](gpu-layout-check.log)، [build](gpu-layout-build.log)، [آزمون‌ها](gpu-layout-tests.log)، [پیوندها](gpu-layout-audit.log)، [اندازه‌ها و تعامل‌های مرورگر](gpu-layout-check.json). انتشار عمومی انجام نشده است.
