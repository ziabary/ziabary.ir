# بازبینی بازطراحی ویزارد LLM — ۱۹ سپتامبر ۲۰۲۶

نسخهٔ محلی؛ بدون commit، push یا deploy.

## تغییر تجربهٔ کاربر

- عنوان اصلی صفحه دوباره اولین H1 است. ویزارد در «از کجا شروع کنیم؟»، بالای چهار مسیر مطالعه قرار دارد. فهرست دسکتاپ از ابتدای صفحه در دسترس است.
- شش مرحله با پرسش‌های وابسته به کاربرد، ورودی، حجم استفاده، محل اجرا، تجهیزات، بودجه و معیار پذیرش. توضیح، کمک درجا، مقصد مقاله و پاسخ مستقل «هنوز مشخص نیست» برای هر پرسش وجود دارد.
- پاسخ‌ها در localStorage همین مرورگر حفظ می‌شوند و «شروع مجدد» آن‌ها را حذف می‌کند. نسخهٔ قدیمی sessionStorage و پارامترهای قدیمی ویزارد به ذخیره‌سازی تازه منتقل می‌شوند؛ بودجه و جزئیات سازمان برای نگهداری پاسخ‌ها به URL نوشته نمی‌شوند. زبان واقعی کار از زبان رابط مستقل است.
- نتیجه در dialog بومی با بستن، Escape، بازکردن دوباره و دکمهٔ ویرایش است: خلاصهٔ هشت‌تایی، حداکثر سه مدل، اجزای بازیابی در صورت ارتباط، روش اجرا، توضیح و مطالعه، راهنمای فنی و شرح کار پیمانکار.
- همهٔ بخش‌ها از یک نتیجه و همان شناسه‌های کاتالوگ استفاده می‌کنند. لینک جدول، فقط مدل‌های همان نتیجه را نمایش می‌دهد و امکان نمایش دوبارهٔ همهٔ مدل‌ها دارد.
- تماس فقط با کنش واقعی کاربر آشکار می‌شود. در خروجی اولیهٔ HTML/JS/JSON/map ایمیل آشکار وجود ندارد.

## منطق و حدود پیشنهاد

فهرست‌های مقایسه به‌صورت تحریریه‌ای برای نقش‌های متن، استخراج، تصویر، تکمیل کد، عامل کدنویسی و ابزار انتخاب شده‌اند. مشخصات، نسخه، شرایط مجوز و مسیرهای اجرا از همان مخزن دادهٔ سایت می‌آیند؛ این فهرست رتبه‌بندی بنچمارک یا تضمین بهترین مدل نیست.

هم‌زمانی و توکن‌های ورودی/خروجی در محاسبهٔ حافظه و آزمون بار وارد می‌شوند. فقط artifact واقعی با هندسهٔ پشتیبانی‌شده وارد فرمول KV می‌شود. سناریوی عددی، یک دستگاه و فعال‌بودن همهٔ درخواست‌های هم‌زمان را فرض می‌کند؛ صف، سرعت و ظرفیت موفق از آن استخراج نمی‌شود. صفحات به عدد قطعی توکن و حافظهٔ چند GPU به یک مخزن فرضی تبدیل نمی‌شوند. برای داده‌های نامشخص، فرض عددی پنهان ساخته نمی‌شود.

تعداد کاربران و افزایش بودجه، به‌تنهایی نامزدها را بزرگ‌تر نمی‌کنند. بازچینش فقط در شاخهٔ مشکل رتبه‌بندی پیشنهاد می‌شود. تغییر اسناد به نوشتن ساده، اجزای بازیابی را حذف می‌کند. مسیر API عمومی به اجازهٔ صریح پردازش بیرونی وابسته است و بخش خرید GPU ندارد. در فارسی مجوز وارد حذف یا وزن‌دهی نامزدها نمی‌شود؛ انگلیسی و اسپانیایی کاربرد و شرایط مجوز را جدا بررسی می‌کنند.

## بررسی‌ها

- `npm run check`: صفر خطا و صفر هشدار.
- `npm run build`: خروجی ایستا، سایت‌مپ، JSON-LD و لینک‌های کوتاه بررسی می‌شوند.
- پنج مجموعهٔ آزمون LLM، شامل رفتار جدید ویزارد، حافظه، زبان‌ها، مقایسه و داده‌های مرجع.
- مرورگر در فارسی، انگلیسی و اسپانیایی، عرض‌های ۱۴۴۰ و ۳۹۰: جریان واقعی شش‌مرحله‌ای، حفظ پاسخ‌ها در مرورگر، Escape و بازکردن مجدد، تطبیق شناسه‌ها با جدول فیلترشده، لینک‌های مقاله، مسیر API، تغییر به عامل کدنویسی، پنهان‌بودن نسخهٔ بدون show-drafts، کپی با clipboard نامتاح و تماس با صفحه‌کلید.
- کنترل نبود اسکرول افقی صفحه و dialog و نبود خطای runtime.

اجرای مرورگر روی خروجی ساخته‌شده:

```sh
REVIEW_ORIGIN=http://127.0.0.1:5195 node tests/llm-wizard-redesign.review.mjs
```
