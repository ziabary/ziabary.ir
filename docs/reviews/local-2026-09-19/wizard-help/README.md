# متن و راهنمای پرسش‌ها و ذخیرهٔ پاسخ‌ها

تغییرهای محلی ویزارد LLM:

- متن آغازین مطابق عبارت درخواستی کاربر شد؛ «بیشتر بخوانید» به «مقاله مرتبط» تغییر کرد.
- توضیح و کمک فارسی هر ۵۴ پرسش، با مثال و نثر مستقیم بازنویسی شد. ساختار تصمیم و داده‌های مدل تغییر نکردند.
- «نمی‌دانم؛ کمکم کن» علاوه بر توضیح، حداکثر دو کارت مرتبط با همان پرسش باز می‌کند. کارت‌ها از عنوان، تصویر و خلاصهٔ واقعی مقاله و مقصد موجود همان زبان استفاده می‌کنند. محدودیت نمایش پیش‌نویس رعایت می‌شود.
- پاسخ، مبنای عددها، مرحله و وضعیت تکمیل در `llm-wizard-state-v2` در localStorage ذخیره می‌شود. بازکردن تب تازه پاسخ‌ها را برمی‌گرداند؛ «شروع مجدد» کلید را واقعاً حذف می‌کند، بدون پاک‌کردن تنظیمات دیگر سایت.
- پاسخ‌های نسخهٔ قبلی sessionStorage منتقل و نسخهٔ قدیمی پاک می‌شوند. URL قدیمی ویزارد نیز یک‌بار خوانده و پارامترهای `w-*` از آن حذف می‌شوند؛ دسترسی صریح پیش‌نویس باقی می‌ماند.

بررسی‌ها: svelte-check بدون خطا یا هشدار؛ آزمون منطق ویزارد؛ مرورگر در فارسی، انگلیسی و اسپانیایی و عرض‌های ۱۴۴۰ و ۳۹۰، با بررسی بارگذاری تصاویر، مقصد مقاله‌ها، حفظ مرحله، بازیابی در تب تازه، حذف واقعی با شروع مجدد و مهاجرت پاسخ‌های قدیمی.
