# بازبینی محلی راهنمای LLM — ۱۹ سپتامبر ۲۰۲۶

این تغییرات فقط برای نسخهٔ محلی آماده شده‌اند. وضعیت پیش‌نویس راهنما حفظ شده است.

- ورود چهارپرسشی در فارسی، انگلیسی و اسپانیایی؛ مسیرهای جدا برای اسناد، اسکن، دادهٔ زنده، گزارش عددی، استخراج و نقش‌های برنامه‌نویسی.
- پیشنهادهای کوچک از کاتالوگ مشترک؛ سیاست مجوز مستقل برای هر زبان؛ معیار پذیرش، مسئول اجرا، لینک فیلترشده و خلاصهٔ قابل کپی.
- ۱۱ مدل تازه: GLM-5/5.1/5.2/5.3-BF16، Kimi-K2.6/K2.7-Code/K3، Qwen3-VL-Embedding/Reranker در اندازه‌های 2B و 8B.
- ۱۶ نتیجهٔ تازه؛ حفظ ۱۲ مشاهدهٔ قبلی E5 بدون درج مجدد. جمع کاتالوگ ۱۱۱ مدل و نتایج پس از ادغام ۱۲۶۷ رکورد است.
- انتخاب آزمون، زبان، معیار و cutoff برای ستون نتیجه؛ گروه‌بندی نتایج متفاوت و حفظ شرایط هر گزارش.
- دو مسیر مستند MLX با فایل‌های 4-bit و نسخهٔ تبدیل 0.24.0 و 0.26.2؛ مستندات ناشر به‌عنوان موتور شمرده نمی‌شوند.
- بخش چهارمسیرهٔ آماده‌سازی داده در مقالهٔ RAG هر سه زبان؛ پاک‌سازی دستورهای ویراستاری و محدودیت مجوز در توصیه‌های فارسی.
- جایگزینی RAM طبق مشاهدهٔ ثبت‌شده در بستهٔ ورودی با V-Color 64GB به قیمت ۲۳۵ میلیون تومان؛ قیمت‌های دیگر متعلق به ۱۶ سپتامبر باقی مانده‌اند. جمع ۱٬۱۱۶٬۱۰۰٬۰۰۰ و سرشکن ۲۴ماهه ۴۶٬۵۰۴٬۱۶۷ تومان است.

## حدود داده

تعداد فعال GLM-5.1 و GLM-5.2 از مقدار ذخیره‌شدهٔ مخزن استنتاج نشده است. نتیجهٔ GLM-5.3، آزمون اثبات‌شدهٔ artifact با BF16 معرفی نمی‌شود. MMEB/ViDoRe شاهد اختصاصی فارسی نیست. برای معماری‌های بدون فرمول معتبر KV، برآورد عمومی ساخته نشده است. تبدیل‌های MLX نام مدل پایه را مشخص می‌کنند، اما revision دقیق وزن پایه را تثبیت نمی‌کنند.

## بررسی‌ها

اعتبارسنجی داده و ترجمه‌ها، typecheck، آزمون‌های انتخاب/مجوز/مقایسه/حافظه/هزینه و مرورگر در سه زبان موفق بودند. `npm run build` نیز موفق بود: ۱۹۷ صفحهٔ قابل نمایه‌سازی در sitemap، ۲۲۷ بلوک دادهٔ ساختاریافته و ۲۳۸ مقصد لینک کوتاه اعتبارسنجی شدند. مرورگر چهار مرحله، شاخه‌های اسکن و گزارش، اعمال فیلتر، Back و reset، تماس با صفحه‌کلید، کپی دستی هنگام شکست Clipboard، عرض ۳۹۰ پیکسل و حالت روشن/تیره را بررسی می‌کند. نشانی تماس در HTML، JavaScript، JSON و source map خروجی نباید plaintext باشد؛ این شرط پیش از آزمون مرورگر کنترل می‌شود.

فایل آزمون مرورگر: `tests/llm-update-20260919.review.mjs`؛ پیش‌نمایش محلی آن روی پورت ۵۱۹۵ و مرورگر CDP روی ۹۳۳۴ است. تصاویر همین پوشه خروجی این بازبینی‌اند.
