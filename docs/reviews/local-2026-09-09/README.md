# نسخهٔ محلی برای بازبینی مهران

تاریخ مبنا: ۹ سپتامبر ۲۰۲۶. تغییرات جدید کاربر ابتدا با کامیت **8422e90 — Preserve recent publications and expanded article excerpts** حفظ شدند. تغییرات این دستورکار محلی‌اند و برای بازبینی در diff ریپو باقی مانده‌اند. deploy، آپلود، push، merge، پاک‌سازی CDN و تغییر DNS انجام نشده است.

## اجرا

در ریشهٔ ریپو:

```bash
npm run build
npm run preview:local
```

نشانی: **http://127.0.0.1:4186/**. این سرور همین حالا در محیط کار اجراست. اگر پورت را برای اجرای جداگانه تغییر می‌دهید: `PORT=4188 npm run preview:local`.

خروجی از `build/` خوانده می‌شود؛ مسیر بی‌فایل ۴۰۴ است و fallback توسعه وجود ندارد. برای نصب تازه، وابستگی‌ها با `npm ci` از lockfile نصب می‌شوند. محیط آزموده‌شده: Node 20.20.0، npm 10.8.2 و ImageMagick (`convert`/`identify`) برای تولید اندازه‌های تصاویر. نسخه‌های lock: Svelte 5.56.8، SvelteKit 2.70.2، mdsvex 0.12.8، adapter-static 3.0.10 و Vite 7.3.6. معماری ایستا و CSS موجود حفظ شده‌اند.

به‌روزرسانی ۱۲ سپتامبر ۲۰۲۶: به درخواست صاحب سایت، وضعیت مجموعه‌های GPU انگلیسی و اسپانیایی به منتشرشده اصلاح شد. هر دو مجموعه اکنون در همین build محلی روی پورت ۴۱۸۶، فهرست راهنماها، جست‌وجو و sitemap حضور دارند. گزارش‌ها و اعداد آزمون‌های پایین مربوط به اجرای اولیهٔ ۹ سپتامبر هستند.

موجودی منتشرشدهٔ مقاله‌ها حفظ شده است: **۵۴ فارسی، ۲۱ انگلیسی و ۱۳ اسپانیایی**. فقط خلاصهٔ ناقص سفرنامهٔ دوم چین از متن همان نوشته اصلاح شد؛ checksum متن دو یادداشت تازه و سایر مقاله‌ها تغییر نکرده است. فایل‌های دادهٔ GPU/سرور، ترجمه‌های آن‌ها، ترتیب related، داده‌های رزومهٔ EN/ES و PDFها حفظ شده‌اند. [گزارش حفظ محتوا](content-preservation.json)

تمام ۱۳۸۷ فایل WebP تولیدشده سالم‌اند؛ ۳۴۶ مسیر تصویر اصلی به آن‌ها ارجاع می‌دهند و فایل‌های اصلی محفوظ‌اند. یک تصویر مشترک ممکن است چند مسیر داده داشته باشد؛ شمار مسیرها با شمار فایل‌های یکتا یکسان نیست. SVGها raster نشده‌اند و بزرگ‌نمایی مقاله از تصویر اصلی استفاده می‌کند. [اعتبارسنجی تصاویر](image-validation.json)

از ۳۹ پیوند منبع مقاله‌های منتشرشده، ۳۸ مورد پاسخ موفق داشت و یک مورد قابل‌بررسی نبود؛ ۴۰۴ تأییدشده‌ای در این نمونه ثبت نشد. این آزمون همهٔ منابع بیرونی داخل متن و جدول‌ها را پوشش نمی‌دهد. [جزئیات پیوندها](external-links.json)

کنترل خصوصی محلی، شمارهٔ موجود در CV را در ۲۶۲ فایل HTML/JS/JSON خروجی پیدا نکرد. خود شماره در گزارش ثبت نشده است. [نتیجه](privacy-check.json)

## تغییرات اصلی و محدودیت‌های روشن

- `publication.mjs`، `translations.mjs`، `translation-groups.json` و `editions.ts`: انتشار مستقل، رابطهٔ اختیاری و صریح زبان‌ها؛ تاریخ تقویمی بدون جابه‌جایی timezone. HTML در prerender زبان و جهت درست می‌گیرد.
- `ArticleArchive.svelte` و مسیرهای `articles/page/[page]`: صفحه‌بندی واقعی ایستا؛ جستجو و فیلتر در query با canonical پایه و noindex. `search.mjs` و نمایه‌های هر زبان، نتایج واقعی و رتبه‌بندی عنوان را پشتیبانی می‌کنند.
- `ArticlePage.svelte`، `ArticleToc.svelte` و `markdown-headings.mjs`: فهرست سبک، IDهای زمان build، لینک واقعی بخش و namespace فصل‌ها.
- `GuidePage.svelte`: متن علمی همچنان در HTML وجود دارد و native details آن را جمع می‌کند؛ این راهکار lazy rendering کامل نیست. HTML راهنمای GPU کمتر شده، اما همچنان متن فصل‌ها و ابزارهای ضروری را دارد.
- `topics.ts`: موضوع، قالب و پروژه جدا هستند؛ دسته‌های قبلی حفظ شده‌اند. صفحات موضوعی انتخاب دستی‌اند و در زبان دیگر دستهٔ خالی ساخته نشده است.
- `MediaEntry.svelte`، `PresentationDetail.svelte` و `resumes/fa.json`: خلاصهٔ قابل بازکردن، دریافت نزدیک معرفی و دادهٔ مشترک مسئولیت‌ها.
- `prepare-assets.mjs`، `images.ts` و زیرمجموعهٔ آیکون‌ها: srcset، ابعاد، قلم WOFF2 و حفظ اصل تصویر. هشدار Vite دربارهٔ اندازهٔ بعضی chunkها باقی است؛ موفقیت build را به معنی حذف این هزینه نگرفته‌ایم.

۱۱ اختلاف تاریخ، عنوان فارسی و نقش کتاب، مبنای عدد سابقه و وضعیت دو مجموعهٔ GPU در [CONTENT-REVIEW.md](../../../CONTENT-REVIEW.md) ثبت شده‌اند. تاریخی حدس زده نشده و گزارش‌های رسانه‌ای بدون eventId معتبر ادغام نشده‌اند. پیش‌نمایش چند اسلاید تازه تولید نشده؛ جلد معتبر موجود حفظ شده است. آزمون ۲۰۰٪ با viewport معادل ۷۲۰ CSS pixel و DPR=2 انجام شده، نه کنترل zoom رابط Chrome؛ ارزیابی بصری native zoom نیز هنگام بازبینی کاربر ممکن است.

## پیکربندی لازم پیش از انتشار بعدی

قواعد آماده در [config/redirects.json](../../../config/redirects.json) هستند و سرور محلی آن‌ها را آزمایش می‌کند. `scripts/deploy-object-storage.mjs` فقط فایل می‌فرستد و تنظیم CDN را تغییر نمی‌دهد؛ این JSON به‌تنهایی روی میزبان S3 اجرا نمی‌شود.

پس از تأیید صریح نسخهٔ بازبینی‌شده، قواعد باید در لایهٔ HTTP/CDN واقعی اعمال شوند: `/gallery/` به `/media/#photos` با ۳۰۸؛ مسیر page/1 هر زبان به آرشیو پایه؛ query قدیمی `?page=N` به مسیر معتبر همان صفحه و مقادیر خارج از بازه به ۴۰۴. مسیرهای فیلتر دارای `q` یا `category` نیز باید `X-Robots-Tag: noindex, follow` بگیرند، همانند سرور محلی. نوع یا endpoint تنظیمات CDN حدس زده نشده و تغییر بیرونی انجام نشده است.

ساخت sitemap اکنون فقط sitemap را تولید می‌کند؛ بازنویسی قبلی hreflang از روی شباهت مسیر و x-default خودکار حذف شده است. این کار سازگاری HTML عادی و فایل‌های precompressed را نیز حفظ می‌کند. مبنای سیاست: [نسخه‌های زبانی گوگل](https://developers.google.com/search/docs/specialty/international/localized-versions)، [صفحه‌بندی گوگل](https://developers.google.com/search/docs/specialty/ecommerce/pagination-and-incremental-page-loading) و [prerender در SvelteKit](https://svelte.dev/docs/kit/page-options).

راهنمای نگهداری ترجمه، انتشار planned، فهرست، taxonomy و دارایی‌ها: [editorial-workflow.md](../../editorial-workflow.md).

**این مرحله در تحویل محلی متوقف می‌شود. انتشار عمومی نیازمند تأیید صریح بعدی مهران است.**
