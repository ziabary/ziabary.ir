«دقیق‌ترکردن پیشنهاد» به نخستین سؤال مؤثرِ بی‌پاسخ می‌رود. پاسخ‌ها در localStorage باقی می‌مانند و شروع مجدد آن‌ها را پاک می‌کند. دکمهٔ بستن و سربرگ پنجرهٔ نتیجه، اسکرول هماهنگ با جداول و کلاس `fa-num` ورودی‌ها حفظ شده‌اند.

## منابع و حدود داده‌ها

- [Hy-MT2، کارت رسمی Tencent](https://huggingface.co/tencent/Hy-MT2-1.8B): اندازه‌ها، زبان‌ها، مجوز، قالب ترجمه و دستورهای اجرا.
- [TranslateGemma، کارت رسمی Google](https://huggingface.co/google/translategemma-4b-it) و [گزارش فنی](https://arxiv.org/pdf/2601.09012): سقف ورودی و جهت‌های ترجمهٔ مستند. برای فارسی، شاهد آموزش انگلیسی به فارسی ثبت شده؛ از آن پشتیبانی جهت معکوس یا کیفیت اندازه‌گیری‌شدهٔ فارسی نتیجه‌گیری نشده است.
- [MADLAD-400](https://huggingface.co/google/madlad400-3b-mt): معماری T5، پیشوند زبان مقصد و بسته‌های اجرا.
- [NLLB-200](https://huggingface.co/facebook/nllb-200-distilled-600M): مرجع پژوهشی با مجوز غیرتجاری؛ طول ۵۱۲ توکنِ آموزش به‌عنوان سقف فیزیکی ورودی مدل ثبت نشده است.
- [Qwen-MT](https://www.alibabacloud.com/help/en/model-studio/machine-translation): زبان‌های خدمت، سقف ورودی و قرارداد `translation_options`.
- [Qwen3.7 Plus](https://www.alibabacloud.com/help/en/model-studio/qwen3-7-plus) و [Qwen3.7 Max](https://www.alibabacloud.com/help/en/model-studio/qwen3-7-max): نسخه، ارائه‌دهنده و محدودیت‌های خدمت.

فهرست API، فهرست همهٔ عرضه‌کنندگان نیست. در این بازبینی برای خدمات ثبت‌شده مسیر سنگاپور بررسی شده است؛ انتخاب منطقه یا ارائه‌دهندهٔ دیگر، به معنی نبود آن خدمت در جهان نیست و صرفاً نامزد تأییدشده‌ای در این فهرست ندارد. این بخش با مثال قیمت API متفاوت است؛ مثال سنگاپور در نسخهٔ فارسی همچنان نمایش داده نمی‌شود.

وزن مدل‌ها دانلود و روی GPU اجرا نشده‌اند. کیفیت ترجمه، سرعت، حافظهٔ کامل بسته‌های جدید و دسترسی واقعی حساب API اندازه‌گیری نشده‌اند. تأیید دسترسی در ویزارد، پاسخ کاربر است. مدل‌های مشروط با همین محدودیت نمایش داده می‌شوند. منابع و فهرست فایل‌ها در `data/llm/sources/translation-review-2026-09-20/` و واردکنندهٔ تکرارپذیر در `scripts/import-llm-translation-review.py` نگهداری می‌شوند.

## بررسی نسخهٔ محلی

- آزمون‌های منطق و بازگشت: `npm test`؛ ۲۲۶ آزمون.
- بررسی TypeScript/Svelte و ترجمه‌های داده: `npm run check`.
- اعتبارسنجی مجموعه: `npm run verify:llm`.
- ساخت استاتیک، sitemap، JSON-LD و لینک‌های کوتاه: `npm run build`.
- آزمون تعاملی: `tests/llm-wizard-review-20260920.review.mjs`؛ پیش‌نمایش روی پورت ۵۱۹۵ و Chromium/CDP روی ۹۳۳۴.

این گزارش، نتیجهٔ بررسی نسخهٔ محلی پیش از انتشار است.

### نتیجهٔ نهایی

همهٔ بررسی‌های بالا موفق شدند: ۲۲۶ آزمون، صفر خطا و صفر هشدار در `check`، اعتبارسنجی داده‌ها و ساخت کامل. ساخت، ۲۰۰ صفحهٔ قابل نمایه‌سازی، ۲۲۷ بلوک JSON-LD و ۲۵۹ مقصد لینک کوتاه را نیز اعتبارسنجی کرد.

آزمون مرورگر در هر سه زبان موفق بود: جست‌وجو و انتخاب چند زبان، حفظ پاسخ پس از بارگذاری مجدد، سؤال کدنویسی در مسیر کوتاه، ترجمهٔ آرشیو بدون RAG ناخواسته، کارت‌های مستقل API، تمرکز روی سؤال تکمیلی، بازکردن دوبارهٔ نتیجه و نبود اسکرول افقی در عرض ۳۹۰ پیکسل. خطای اجرای JavaScript ثبت نشد. دو ایراد شناسایی‌شده در این آزمون، به‌روزنشدن فهرست هنگام جست‌وجو و تقدم سؤال مدت هزینه بر دسترسی API، پیش از تأیید نهایی اصلاح شدند.
