# لینک مستقیم بخش فعال

با اسکرول متن، شناسهٔ همان بخشی که در فهرست مطالب فعال است در آدرس‌بار قرار می‌گیرد. تغییر با API جایگزینی آدرس SvelteKit و پس از توقف کوتاه اسکرول انجام می‌شود؛ مسیر صفحه، پارامترهای جست‌وجو و state مسیریاب حفظ می‌شوند و ورودی جدیدی به تاریخچه افزوده نمی‌شود. برگشت به ابتدای صفحه شناسهٔ بخش قبلی را پاک می‌کند.

دکمه‌های کپی و اشتراک‌گذاری لینک بخش فعال را استفاده می‌کنند. در راهنماها، هر یادداشت فقط شناسه‌های متعلق به خودش را به اشتراک می‌گذارد. پیوندهای کوتاه قبلی همچنان برای مقصدهای ثبت‌شده استفاده می‌شوند؛ زیربخش‌ها لینک کامل با fragment دارند.

ورود به لینک مستقیم پس از آماده‌شدن فونت‌ها تراز می‌شود تا جابه‌جایی متن هنگام بارگذاری، مقصد ارجاع را تغییر ندهد. در LLM یادداشت بسته نیز برای مقصد باز می‌شود. پارامتر show-drafts=true حفظ شده و وضعیت انتشار راهنما تغییر نکرده است.

## بررسی

- npm run check: صفر خطا و هشدار.
- npm run build: موفق، همراه اعتبارسنجی sitemap، JSON-LD و لینک‌های کوتاه.
- npm test: ۱۴۸ موفق.
- tests/section-urls.review.mjs: هشت مسیر شامل سه زبان، GPU، ZTAI و LLM؛ همسانی آدرس و منو، حفظ query، بارگذاری مجدد، کپی و اشتراک‌گذاری، ثابت‌ماندن تاریخچه و کنترل موبایل. رفت‌وبرگشت تاریخچه پس از کلیک منو در مقالهٔ فارسی و LLM نیز بررسی شد.
- tests/reading-share.review.mjs: نه مسیر؛ جای دکمه‌ها، نبود تداخل با منو و لینک اشتراک‌گذاری صحیح.
