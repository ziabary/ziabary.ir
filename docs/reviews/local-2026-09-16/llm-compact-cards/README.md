# کارت‌های فشرده و کنترل باز و بسته‌شدن مقاله‌ها

- کارت‌های زیر جدول افقی شدند؛ تصویر کوچک کنار عنوان و خلاصه قرار دارد.
- نمایشگر عریض سه ستون، دسکتاپ دو ستون و موبایل یک ستون دارد.
- محدودیت دو مقاله حذف شد؛ همهٔ پیوندهای منتخب موجود نمایش داده می‌شوند.
- علامت‌های بعلاوه و ضربدر با SVG و مرکز هندسی ثابت جایگزین نویسهٔ فونت شدند.
- چیدمان عریض جدول‌ها و معرفی حفظ شده است.

نسخهٔ محلی: http://localhost:4189/guides/llm/

فرمان اجرا: `PORT=4189 npm run preview:local`

تصاویر و نتیجهٔ بررسی مرورگر در همین پوشه ذخیره می‌شوند. تغییرات منتشر نشده‌اند.
