# اشتراک‌گذاری هنگام خواندن

کنترل‌های اشتراک‌گذاری از ابتدای مقاله به انتهای متن منتقل شدند. کنترل شناور از ابتدای ورود متن به دید، با فاصلهٔ ۱۶ پیکسل از لبهٔ متن در سمت مقابل فهرست مطالب ظاهر می‌شود و با رسیدن به کنترل‌های انتهایی کنار می‌رود. جای آن با تغییر عرض صفحه از روی خود متن و محل واقعی فهرست مطالب محاسبه می‌شود؛ در نوشتهٔ فارسیِ دارای منوی چپ، دکمه‌ها سمت راست هستند. در راهنماهای دارای منوی راست، دکمه‌ها سمت چپ می‌مانند؛ اگر حاشیهٔ کافی نداشته باشد، به حالت کوچک پایین چپ می‌رود. در موبایل، دکمهٔ کوچک پایین چپ با لمس باز می‌شود؛ Escape آن را می‌بندد. یادداشت بسته کنترل شناور ندارد.

این رفتار در مقاله‌های مستقل فارسی، انگلیسی و اسپانیایی و یادداشت‌های داخل راهنماهای GPU، ZTAI و LLM اعمال شده است. پیش‌نمایش LLM همچنان به `show-drafts=true` نیاز دارد و لینک اشتراک‌گذاری آن نیز این پارامتر را حفظ می‌کند.

## نتیجهٔ بررسی

- `npm run check`: بدون خطا و هشدار.
- آزمون‌های واحد: ۱۴۸ موفق، صفر ناموفق.
- `npm run build`: موفق؛ اعتبارسنجی نقشهٔ سایت، داده‌های ساختاریافته و لینک‌های کوتاه موفق.
- `node tests/reading-share.review.mjs`: نه مسیر موفق؛ بررسی نمایش از ابتدای متن، فاصله از متن، عرض‌های ۹۰۰، ۱۱۹۹، ۱۲۰۰، ۱۳۰۶، ۱۶۰۰ و ۲۲۰۰ پیکسل و نبود هم‌پوشانی با فهرست مطالب، میانه و انتهای متن، مقصد کپی و اشتراک‌گذاری با API شبیه‌سازی‌شده، بسته‌شدن یادداشت و کنترل موبایل.
