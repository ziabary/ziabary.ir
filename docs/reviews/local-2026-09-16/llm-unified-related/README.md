# یکپارچه‌سازی کارت‌های مرتبط در راهنمای LLM

بخش جداگانهٔ «مطالب مرتبط در ziabary.ir» و پیوند آن در فهرست حذف شد. مقالات مرتبط با مفاهیم جدول‌ها، با استفاده از نگاشت تحریری موجود، در همان کارت‌های زیر جدول نمایش داده می‌شوند. هر کارت تصویر، عنوان، خلاصه و زمان مطالعه دارد. یادداشت‌های درج‌شده در راهنما داخل همان صفحه باز می‌شوند؛ سایر کارت‌ها به مقاله و زیرعنوان مرتبط می‌روند.

تغییرات محلی‌اند؛ انتشار عمومی انجام نشده است.

پیش‌نمایش: http://localhost:4189/guides/llm/

```sh
PORT=4189 npm run preview:local
```

- npm run check: بدون خطا و هشدار
- npm run build: موفق، همراه با اعتبارسنجی نقشهٔ سایت و پیوندهای کوتاه
- npm test: ۱۴۴ آزمون موفق
- آزمون مرورگر: دسکتاپ ۱۶۰۰، موبایل ۳۹۰ و ۳۲۰ پیکسل؛ تم روشن و تیره؛ بدون خطای زمان اجرا یا بیرون‌زدگی متن کارت‌ها
- تمام مقصدها و زیرعنوان‌های کارت‌های افزوده‌شده بررسی شدند.

جزئیات و تصاویر در browser-review.json و فایل‌های PNG همین پوشه هستند.
