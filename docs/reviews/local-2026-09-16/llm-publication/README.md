انتشار مجموعهٔ LLM — ۲۵ شهریور ۱۴۰۵

دو بستهٔ جدید ادغام شدند و همراه هشت یادداشت آمادهٔ قبلی از حالت پیش‌نویس خارج شدند. خود راهنمای LLM نیز عمومی شد و در فنی‌جات، جست‌وجو، نقشهٔ سایت و لینک‌های کوتاه قرار گرفت. چهار عنوانِ نوشته‌نشده (پارامتر کل و فعال، انتخاب نسخهٔ DeepSeek، مجوز مدل و تفکیک اجزای سرویس) از فهرست تحریریه و مسیرهای مطالعه حذف شدند؛ بخش «یادداشت‌های در حال آماده‌سازی» و مدخل‌های منوی آن هم حذف شد.

نشانی‌ها:

- [راهنمای LLM](https://ziabary.ir/guides/llm/)
- [مقایسهٔ Ollama، vLLM، SGLang و llama.cpp](https://ziabary.ir/articles/ollama-vllm-sglang-or-llama-cpp/) — تاریخ ۲۴ شهریور؛ آخرین بررسی ۲۵ شهریور.
- [هزینهٔ واقعی اجرای مدل؛ خرید، اجاره یا API](https://ziabary.ir/articles/true-llm-cost-buy-rent-or-api/) — تاریخ ۲۵ شهریور.

تاریخ هشت مقالهٔ قبلی حفظ شد. دو مقالهٔ تازه بعد از آن‌ها قرار گرفتند تا قیمت‌ها و نسخه‌های بررسی‌شده نسبت به تاریخ متن از آینده نباشند. پیوند مقالهٔ نرم‌افزار به مقالهٔ هزینه برداشته شد؛ مقالهٔ هزینه می‌تواند به نرم‌افزارِ قدیمی‌تر ارجاع دهد. دو ارجاع قبلی به پیش‌نویسِ «RAG و Agent امن» نیز از متن مقاله‌های عمومی برداشته شد. خود آن پیش‌نویس منتشر نشد.

متن کامل مقاله‌ها همچنان صفحهٔ مستقل دارد. زیر جدول‌ها، عنوان مقالهٔ مرتبط و زمان مطالعه نشان داده می‌شود. جدول‌ها در جای فعلی باقی مانده‌اند؛ افزودن متن کامل مقاله‌ها به خود راهنما تصمیم این انتشار نبوده است. کاورها محلی‌اند و نسخهٔ WebP و اندازه‌های واکنش‌گرا دارند. جدول هزینهٔ اجارهٔ حذف‌شده از دیتاست LLM برگردانده نشده است؛ مقایسهٔ هزینه فقط محتوای مقالهٔ تازه است.

برای عمومی‌شدن راهنما، HTML جدول‌ها پیش‌رندر شد و خواندن تنظیمات نشانی به مرورگر محدود شد. لینک‌ها بدون `show-drafts` کار می‌کنند و هر صفحه canonical مستقل دارد. فهرست مجموعه‌ها فقط فرادادهٔ سبک LLM را وارد می‌کند و به دیتاست کامل آن وابسته نشده است.

بررسی‌ها:

- `npm run check`: صفر خطا و صفر هشدار.
- `npm run build`: موفق؛ ۱۸۶ نشانی قابل‌ایندکس، ۱۹۵ بلوک JSON-LD و ۲۲۷ مقصد لینک کوتاه اعتبارسنجی شد.
- `npm test`: ۱۴۴ آزمون موفق، بدون شکست یا کنارگذاشتن آزمون.
- [ممیزی استاتیک](static-audit.json): ۱۹۸ صفحه، صفر خطای مسیر و صفر خطای نشانی بخش‌ها.
- [بازبینی مقاله‌ها](browser-review.json): هر ده مقاله، ۴۲ جدول، کاورها، تاریخ‌ها، KaTeX، جهت نوشتار و لینک‌ها؛ دسکتاپ و موبایل ۳۲۰/۳۹۰ پیکسل؛ صفر خطای زمان اجرا.
- [بازبینی راهنما](../llm-public-guide/browser-review.json): فیلترها و مقایسه‌ها، پروندهٔ مدل، ۳۳۶ تصویر محلی و ۳۵ پیوند داخلی؛ صفر خطای زمان اجرا.
- [کنترل نسخهٔ عمومی](live-check.json): هر ۱۸ نشانی HTTP 200 و محتوای کاملاً برابر با خروجی محلی داشتند.
- [آزمون مرورگر روی دامنهٔ اصلی](../llm-public-guide-live/browser-review.json): هر ۱۲ بررسی راهنما موفق، ۳۳۶ تصویر محلی و ۳۵ پیوند داخلی سالم، بدون خطای زمان اجرا.
- انتشار با `npm run deploy`: تعداد ۱٬۰۲۴ فایل بارگذاری، ۲٬۲۴۱ فایل بدون تغییر و ۲۷۰ فایل منسوخ پاک‌سازی شد.

در کنترل نمونه‌ایِ قیمت‌های ورودی مقاله، نرخ GPT-4.1 Mini با [مستندات اول ای‌آی](https://docs.avalai.ir/fa/models/gpt-4.1-mini) و قیمت RTX 4090 با [تعرفهٔ Runpod](https://www.runpod.io/pricing) همسان بود. تاریخ مشاهدهٔ قیمت‌ها در متن حفظ شد و مثال‌ها وارد دیتاست بنچمارک نشده‌اند.
