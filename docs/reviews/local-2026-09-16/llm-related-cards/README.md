# کارت‌های یادداشت مرتبط زیر جدول‌های LLM

این تغییر فقط در نسخهٔ محلی آماده شده است.

- زیر هر جدول دو کارت مرتبط، شامل کاور محلی، عنوان کامل، خلاصه و زمان مطالعه نمایش داده می‌شود.
- کلیک روی کارت متن کامل همان یادداشت را در پایین صفحه باز می‌کند و به آن می‌رود.
- کارت‌ها در دسکتاپ دو ستونی و در موبایل تک ستونی هستند؛ لینک همهٔ یادداشت‌ها نیز حفظ شده است.
- قاعدهٔ تک‌سطری منو برای کارت‌ها بازنویسی شده تا عنوان و خلاصه در موبایل بریده نشوند.

پیش‌نمایش: http://localhost:4189/guides/llm/

فرمان اجرا پس از ساخت:

```sh
PORT=4189 npm run preview:local
```

اعتبارسنجی: `npm run check` بدون خطا و هشدار، `npm run build` موفق، ۱۴۴ آزمون موجود موفق. بررسی مرورگر شامل بازشدن مقاله، پیوند مستقیم زیرعنوان، عرض‌های ۱۶۰۰، ۳۹۰ و ۳۲۰ پیکسل و تم روشن و تیره است. جزئیات و تصاویر در همین پوشه قرار دارند.
