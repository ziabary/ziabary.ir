# دکمهٔ بازکردن مقاله در تب جدید

در یادداشت‌های داخل مجموعه‌های فنی، کنار دو دکمهٔ اشتراک‌گذاری و کپی لینک، لینک دکمه‌ای «بازکردن مقاله در تب جدید» اضافه شد. این کنترل هم در نوار شناور کنار متن و هم در انتهای متن وجود دارد. در موبایل داخل همان نوار جمع‌شونده قرار می‌گیرد.

- مقصد: صفحهٔ مستقل همان مقاله، با `target="_blank"` و `rel="noopener noreferrer"`.
- آیکون SVG مستقل از فونت، با اندازهٔ کنترل یکسان با دو دکمهٔ دیگر.
- متن دسترس‌پذیر و tooltip به فارسی، انگلیسی و اسپانیایی.
- لینک متنی قبلی بالای یادداشت LLM و لینک‌های تکراری انتهای فصل‌های دارای متن حذف شدند.
- صفحات مستقل مقاله همان دو کنترل اشتراک‌گذاری را دارند.
- پارامتر فعلی پیش‌نمایش LLM (`show-drafts=true`) حفظ شد.

## بررسی

`npm run check`: صفر خطا و صفر هشدار.

`npm run build`: موفق؛ نقشهٔ سایت، داده‌های ساختاریافته و مقصد لینک‌های کوتاه معتبرند.

بررسی مرورگر در `review.json`: GPU فارسی، انگلیسی و اسپانیایی، ZTAI و LLM؛ اندازهٔ یکسان کنترل‌ها، لینک انتهای متن، نمایش موبایل و کلیک واقعی که تب دوم را باز می‌کند و صفحهٔ راهنما را حفظ می‌کند.

تصاویر: [دسکتاپ](./llm-desktop.png)، [موبایل](./llm-mobile.png).

فرمان اجرا: `PORT=4189 npm run preview:local`

مسیرهای بازبینی:

- http://localhost:4189/guides/gpu-selection/
- http://localhost:4189/guides/zero-trust-ai/
- http://localhost:4189/guides/llm/?show-drafts=true

تغییرات فقط محلی‌اند؛ commit، push و deploy انجام نشده است.

آزمون بازگشتی اشتراک‌گذاری نیز در ۹ مسیر و عرض‌های مختلف موفق بود: کپی لینک بخش جاری، اشتراک‌گذاری، کنترل‌های انتهای متن و عدم تداخل با فهرست. برای تثبیت چیدمان پس از resize، زمان انتظار نسخهٔ موقت آزمون از ۲۵۰ به ۱۰۰۰ میلی‌ثانیه افزایش یافت؛ کد برنامه برای این موضوع تغییری نکرد.
