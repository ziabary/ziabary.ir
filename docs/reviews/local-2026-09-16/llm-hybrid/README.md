پیش‌نمایش محلی چیدمان ترکیبی LLM

[بازکردن بخش یادداشت‌ها](http://localhost:4189/guides/llm/#llm-notes)

جدول‌ها بالای صفحه حفظ شده‌اند. ده یادداشت، با کاور کوچک، خلاصه، تاریخ و زمان مطالعه، بعد از جدول‌ها قرار گرفته‌اند و در شروع بسته‌اند. بازکردن هر یادداشت، متن کامل، تصویر، جدول‌ها و فرمول‌های آن را در همین صفحه نشان می‌دهد؛ صفحهٔ مستقل مقاله نیز در دسترس است.

فهرست دسکتاپ و موبایل دو گروه «جدول‌ها» و «یادداشت‌ها» دارد. زیربخش مقالهٔ فعال نیز نمایش داده می‌شود و با اسکرول دنبال می‌شود. نشانی مستقیم یک زیربخش، مقالهٔ بسته را باز می‌کند. زیر هر جدول دو دکمهٔ کوتاه برای توضیح مرتبط و یک مسیر به همهٔ یادداشت‌ها قرار گرفته است.

در موبایل ۳۲۰ پیکسل، عنوان کارت تمام عرض را می‌گیرد تا به سطرهای باریک شکسته نشود. اسکرول فهرست کنار صفحه نیز با تم سایت هماهنگ است.

بررسی‌ها: check بدون خطا یا هشدار، build موفق، ۱۴۴ آزمون موفق. ممیزی ۱۹۸ صفحه، بدون خطای مسیر یا fragment. آزمون مرورگر، ده مقالهٔ بسته، ۴۲ جدول درون مقاله‌ها، شناسه‌های یکتا، بازشدن از دکمه و نشانی مستقیم، هایلایت زیربخش، و نمایش ۳۲۰/۳۹۰ پیکسل در دو تم را تأیید کرد؛ خطای زمان اجرا صفر بود.

```bash
npm run build

```
