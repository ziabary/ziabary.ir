# بازچینی مقدمهٔ GPU و LLM

نسخهٔ محلی، ۱۶ سپتامبر ۲۰۲۶.

- مقدمهٔ مشترک: حداکثر عرض ۱۲۸۰، ستون متن ۶۰٪ در راست و تصویر ۴۰٪ در چپ، فاصلهٔ ۴۰ پیکسل و تراز بالا. عنوان ۳۸ پیکسل و متن ۱۷ پیکسل با ارتفاع خط ۱٫۹؛ تصویر با نسبت اصلی.
- در عرض کمتر از ۹۶۰: متن سپس تصویر با سقف عرض ۴۸۰. در موبایل، مسیرهای LLM و پرسش/پاسخ راهنمای GPU زیر هم‌اند.
- LLM: عنوان فارسی، برچسب کوچک LLM & SLM، دو پاراگراف اصلی، چهار مسیر در شبکهٔ ۲×۲ و نوار مستقل آمار/تاریخ. لینک مقاله سبک متنی دارد.
- GPU: دو پاراگراف در مقدمه؛ پاراگراف سوم بالای جدول راهنمای مطالعه؛ شش ردیف، نه مقصد، ستون پرسش ۵۵٪، جداکننده‌های افقی و فاصلهٔ روشن میان لینک‌ها.
- عرض و فیلترهای جدول‌های تخصصی، شناسه‌های بخش‌ها و نشانی صفحات حفظ شدند. محدودهٔ پایش بخش فعال با جابه‌جایی مقدمه به عنصر اصلی صفحه منتقل شد.

تصاویر `gpu-1440.png`، `gpu-390.png`، `llm-1440.png` و `llm-390.png` کل بخش آغازین تا شروع بخش جدول اول را نشان می‌دهند.

آزمون مرورگر نسبت ستون‌ها، وسط‌چین بودن، نسبت تصویر، ترتیب موبایل، چهار کارت و تفکیک دکمه/لینک، شش ردیف مطالعه و بازشدن نه مقصد GPU زیر نوار ثابت را بررسی کرد؛ بدون خطای JavaScript یا سرریز افقی صفحه. مقادیر واقعی در `review.json` ثبت‌اند. عکس‌ها پس از بارگذاری فونت، آماده‌شدن صفحه و decode کامل تصویر گرفته شده‌اند.

بررسی نهایی: `npm run check` بدون خطا و هشدار؛ `npm run build` موفق، همراه با اعتبارسنجی نقشهٔ سایت، داده‌های ساخت‌یافته و لینک‌های کوتاه؛ آزمون‌های `llm-guide.test.mjs` موفق. دیپلوی انجام نشده است.
