# بازبینی متن راهنمای LLM

متن رابط جدول‌ها، جزئیات مدل، راه‌اندازی، حافظه، نتایج آزمون‌ها، پیشنهاد مدل و منابع مرور شد. متن خود مقالات و داده‌های عددی تغییر نکردند.

- ردیف‌های «نوع منبع»، «ذی‌نفع تجاری» و «این منبع چه چیزی را بررسی می‌کند؟» حذف شدند.
- عبارت‌های قالبی شناسنامه و گزارش ناشر از نمایش کنار گذاشته شدند؛ دادهٔ اصلی منابع برای اعتبارسنجی محفوظ است.
- محدودیت اختصاصی آزمون و وابستگی تجاریِ اطلاعات‌دهنده در توضیحات کوتاه منبع باقی می‌مانند؛ توضیحات یکسان دوباره نمایش داده نمی‌شوند.
- ردیف‌های فاقد اطلاعات در مشخصات منابع مدل نمایش داده نمی‌شوند.
- توضیحات جدول‌ها و برچسب‌ها کوتاه‌تر و فارسی‌تر شدند؛ اصطلاحات داخلی ساختار داده از متن رابط حذف شدند.

پیش‌نمایش: http://localhost:4189/guides/llm/

فرمان اجرا: `PORT=4189 npm run preview:local`

بررسی‌ها: check بدون خطا و هشدار، build موفق، ۱۴۷ آزمون موفق. آزمون مرورگر پنجرهٔ منابع، حذف متن‌های عمومی و حفظ لینک‌ها را بررسی می‌کند. تصویر model-sources.png و browser-review.json در همین پوشه هستند.

این تغییرات محلی‌اند و منتشر نشده‌اند.
