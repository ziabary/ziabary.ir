# بازبینی ریدایرکت زودهنگام — ۱۵ سپتامبر ۲۰۲۶

نسخهٔ محلی ریدایرکت لینک کوتاه، بدون انتظار برای بارگیری صفحهٔ اصلی آماده است. تغییرات قبلی کاربر حفظ شده‌اند. این بازبینی شامل کامیت، پوش، انتشار عمومی یا تغییر تنظیمات آروان نیست.

## تغییر

کد قبلی یک ماژول را به head اضافه می‌کرد؛ آن ماژول resolver را import می‌کرد و سپس نگاشت JSON را از شبکه می‌گرفت. در این فاصله محتوای صفحهٔ اصلی ظاهر می‌شد.

اکنون هنگام prerender، hook موجود اسکریپت مستقل و نگاشت ۲۰۴ مقصد فعال را فقط در ابتدای HTML صفحهٔ `/` درج می‌کند. اسکریپت پیش از CSS، فونت‌ها و کد برنامه، مقصد را پیدا کرده و `location.replace` را اجرا می‌کند. این تغییر سرویس زمان اجرا یا وابستگی جدیدی به سایت اضافه نمی‌کند. حجم اسکریپت و نگاشت حدود ۱۳ کیلوبایت، یا ۳٫۶ کیلوبایت با gzip است.

وجود `t` از همان ابتدا محتوای صفحهٔ اصلی را پنهان می‌کند. کد نامعتبر پیام خطا با لینک بازگشت و `noindex` دارد. صفحهٔ اصلی عادی، query نامرتبط و صفحات سایر زبان‌ها رفتار عادی خود را حفظ می‌کنند. اسکریپت قدیمی صرفاً برای سازگاری با HTML کش‌شده نگه داشته شده است.

## اجرای محلی

```sh
npm run build
LOCAL_SHORT_LINK_MODE=browser PORT=4189 npm run preview:local
```

- لینک معتبر: http://127.0.0.1:4189/?t=ggsiofrgs
- مقصد: http://127.0.0.1:4189/guides/gpu-selection/#int8-or-fp8-real-gpu-support
- خطا: http://127.0.0.1:4189/?t=missing
- صفحهٔ اصلی عادی: http://127.0.0.1:4189/

این حالت پیش‌نمایش، برای لینک کوتاه پاسخ HTTP 200 می‌دهد تا انتقال واقعاً با اسکریپت داخل HTML آزمایش شود. حالت پیش‌فرض سرور محلی همچنان 301 است.

## نتیجهٔ بررسی

- `npm run check`: صفر خطا و صفر هشدار.
- `npm test`: هر ۸۵ آزمون موفق.
- `npm run build`: موفق؛ sitemap شامل ۱۶۸ صفحهٔ indexable تأیید شد.
- اعتبارسنجی هر ۲۰۴ مقصد و fragment، به‌علاوه اجرای اسکریپت واقعی HTML ساخته‌شده برای هر کد: موفق.
- آزمون مرورگر با ارسال دیرهنگام body صفحهٔ اصلی: درخواست مقصد پیش از ارسال body آغاز شد و body صفحهٔ اصلی ارسال نشد.
- آزمون مقصد کند: محتوای صفحهٔ اصلی نمایش داده نشد.
- هیچ درخواست resolver، ماژول short-links یا نگاشت JSON برای انتقال لازم نبود.
- fragment مقصد و canonical صفحهٔ نهایی صحیح؛ لینک کوتاه با replace از تاریخچه حذف شد.
- کد ناشناخته، تکراری و مقصد خارجی جعلی پیام خطا دارند و ریدایرکت نمی‌شوند.
- نمایش موبایل بدون سرریز افقی و با تم روشن/تیره تأیید شد.
- JavaScript خاموش: انتقال انجام نمی‌شود، ولی صفحهٔ اصلی پنهان و غیرقابل استفاده نمی‌شود.
- خطای جاوااسکریپت مرورگر: صفر.

## API و سئو

اسکریپت مرورگر همچنان HTTP 301 تولید نمی‌کند. توضیح مسیر خودکارسازی API آروان، مستندات رسمی بررسی‌شده و موارد نیازمند تأیید (تطبیق query و ظرفیت پلن) در [راهنمای لینک کوتاه](../../deployment/short-links.md) آمده است. هیچ دسترسی مدیریت CDN در این محیط ارائه نشده و هیچ قانون عمومی ایجاد یا تغییر داده نشده است.
