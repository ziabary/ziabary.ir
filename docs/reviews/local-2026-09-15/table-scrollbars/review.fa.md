# اسکرول‌بار هماهنگ با تم جدول‌ها

استایل اسکرول‌بارهای جدول‌های GPU، سرور و LLM، جدول‌های مقایسه و جدول‌های Markdown در `src/app.css` یکپارچه شد. رنگ دستگیره از فیروزه‌ای سایت و رنگ مسیر از پس‌زمینهٔ همان پوسته ساخته می‌شود. دستگیره‌ها گرد، دارای فاصله از لبه و با حالت اشاره و فشردن متمایزند. فلش‌ها و گوشهٔ خاکستری پیش‌فرض حذف شدند.

در مرورگرهای دارای پشتیبانی WebKit، اندازهٔ مسیر ۱۲ پیکسل و حداقل طول دستگیره ۴۰ پیکسل است. برای مرورگرهای دیگر، رنگ و ضخامت از ویژگی‌های استاندارد CSS تنظیم می‌شوند. در حالت رنگ‌های اجباری سیستم، کنترل بومی مرورگر حفظ می‌شود. پیمایش همچنان بومی است و کد جاوااسکریپت یا وابستگی جدیدی اضافه نشد.

فقط استایل مشترک و اعلان‌های تکراری اسکرول‌بار در سه مؤلفه تغییر کرده‌اند. سایر تغییرات قبلی کاربر حفظ شدند.

بازبینی محلی:

```bash
npm run build
PORT=4189 npm run preview:local
```

نتایج:

- `npm run check`: صفر خطا و صفر هشدار.
- `npm run build`: موفق؛ نقشهٔ سایت ۱۷۴ نشانی، ۱۸۳ بلوک دادهٔ ساخت‌یافته و ۲۱۰ مقصد لینک کوتاه معتبرند.
- `git diff --check` برای فایل‌های تغییرکرده: موفق.
- مرورگر Chromium: ۱۵ حالت بررسی شد؛ جدول‌های اصلی و مقایسه، پوستهٔ روشن و تیره، راست‌به‌چپ و چپ‌به‌راست، دسکتاپ و موبایل ۳۹۰ پیکسل. استایل مشترک در همهٔ آن‌ها اعمال شده و سرریز افقی صفحه وجود ندارد.
- پیمایش افقی و عمودی با کلیدهای جهت آزمایش شد؛ حالت رنگ‌های اجباری به تنظیم بومی برگشت. خطای زمان اجرای مرورگر ثبت نشد.
- تغییر فقط CSS است؛ برای این تغییر آزمون واحد جدیدی نوشته نشد. هشدارهای قبلی ساخت دربارهٔ mdsvex و اندازهٔ بسته‌ها همچنان وجود دارند.
