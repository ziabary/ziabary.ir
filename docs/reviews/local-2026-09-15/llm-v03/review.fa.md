# تحویل محلی راهنمای LLM — نسخهٔ دادهٔ ۰٫۳٫۰

بستهٔ `ziabary-llm-data-upgrade-v0.3.0.zip` و گزارش `llm-data-audit-fa.md` در ۲۰۲۶/۰۹/۱۵ با وضعیت فعلی پروژه ادغام شدند. نسخهٔ قابل‌آزمایش در `build/` آماده است. راهنما همچنان پیش‌نویس و `noindex` است و وارد نقشهٔ سایت عمومی نشده است. کامیت، پوش و دیپلوی انجام نشد.

## بازبینی محلی

از ریشهٔ پروژه اجرا کنید؛ اگر پیش‌نمایش روی همین پورت فعال است، نیازی به اجرای دوباره نیست:

```bash
PORT=4189 npm run preview:local
```

- [ورودی راهنما و چهار جدول اصلی](http://127.0.0.1:4189/guides/llm/?show-drafts=true)
- [فهرست مدل‌ها و فیلتر دریافت](http://127.0.0.1:4189/guides/llm/?show-drafts=true#model-catalog): Ollama باید ۶۲ و GGUF باید ۸۵ مدل نشان دهند؛ جست‌وجو و سایر فیلترها تعداد گزینه‌ها را تغییر می‌دهند.
- [حافظه و سخت‌افزار](http://127.0.0.1:4189/guides/llm/?show-drafts=true#hardware-feasibility): حالت «اندازهٔ فایل وزن» ۲۵۷ ردیف دارد؛ حالت بودجهٔ وزن و KV با زمینه و تعداد درخواست فعال تغییر می‌کند.
- [پروندهٔ BGE-M3 و نتایج کیفیت](http://127.0.0.1:4189/guides/llm/?show-drafts=true&model=model%3Abaai-bge-m3&panel=quality): مقدار جدول تخصصی، MIRACL با nDCG@10 برابر ۵۷٫۷، زبان فارسی و روش Dense است؛ سایر زبان‌ها و روش‌ها جدا نگهداری شده‌اند.

## داده و صحت نمایش

| مورد | مقدار نهایی بررسی‌شده |
| --- | ---: |
| مدل / خانواده | ۸۷ / ۲۴ |
| مدل تخصصی | ۲۰ |
| بستهٔ دریافت | ۴۷۵ |
| مدل دارای Ollama / GGUF / ONNX | ۶۲ / ۸۵ / ۱۵ |
| نتیجهٔ کیفیت / مدل دارای نتیجه | ۱۱۰۱ / ۸۵ |
| مسیر اجرا و سازگاری | ۳۰۵ |
| ردیف اندازهٔ فایل / مدل تحت پوشش | ۲۵۷ / ۸۷ |
| ردیف پیش‌فرض بودجهٔ GPU | ۵۶ |
| اجرای کارایی و پیشنهاد قیمت حفظ‌شده از مکمل | ۴۰ / ۱۶ |

همهٔ ستون‌های اصلیِ نمای پیش‌فرض چهار جدول مقدار قابل نمایش دارند؛ این شامل توضیح کاربرد و شروط انتخاب نیز هست و به معنی وجود امتیاز عددی برای همهٔ موارد نیست. ماتریس کاربرد، ۶۷ مدل مولد و چندوجهی را در هفت کاربرد پوشش می‌دهد. Mistral-7B-Instruct-v0.3 و ModernBERT-base امتیاز عددی قابل انتساب در این مجموعه ندارند؛ مشخصات، نقش و روش دریافتشان نمایش داده می‌شود.

اندازهٔ فایل وزن به‌عنوان حداقل VRAM معرفی نمی‌شود. محاسبهٔ وزن و KV به معماری و زمینه و هم‌زمانی وابسته است؛ استفاده از چند GPU نیاز به تقسیم مدل را حفظ می‌کند. نتایج Thinking، دسترسی به ابزار، زبان و ابعاد embedding با نتایج متفاوت یکسان نشده‌اند. آزمون استنتاج تازه‌ای اجرا و فایل کامل وزن مدل‌ها دانلود نشد.

سه ادعای مثبتِ قدیمی دربارهٔ اجرای آفلاین vLLM، SGLang و llama.cpp با فیلدهای نامعلومِ متناظر در خود بسته تناقض داشتند. آن سه رکورد حذف و دلیل آن در [ثبت اصلاح ادغام](../../../../data/llm/v0.3.0/research/integration-corrections.json) ثبت شد؛ منابع و وضعیت نامعلوم حفظ شدند. همهٔ فیلدهای خروجی یکپارچه با مرجع بسته، به‌جز همین سه ادعا، دقیقاً یکسان‌اند.

۸ لوگوی جدید محلی برای خانواده‌ها و نرم‌افزارها ذخیره شد؛ E5 و SmolVLM از نشان‌های محلی موجود استفاده می‌کنند. همهٔ ۲۴ خانواده به فایل محلی معتبر متصل‌اند. [منابع و هش لوگوها](../../../../data/llm/v0.3.0/research/local-brand-assets.json) ثبت شده است.

## حفظ تغییرات موجود

هر ۲۵ فایل وابستهٔ مکمل ۰٫۲ با هش‌های بسته تطابق داشت؛ مکمل بازنویسی نشد. سه فایل با مبنای ارسالی متفاوت بودند و اختلاف‌ها با حفظ تغییرات محلی ادغام شدند: بازنشانی فیلتر هنگام تعویض مدل، محدودکردن فیلتر مدل به جدول مربوط، جزئیات معماری و گروه‌بندی معیارهای کارایی و هزینه باقی ماندند.

از ۴۳۶ فایل موجودِ ثبت‌شده پیش از کار، هیچ فایلی حذف نشد. مقاله‌ها و ترجمه‌های تازه، ارتباط دستی با مقالهٔ RAG، کاور و باکس شروع LLM، کارت‌های شروع GPU و محدودیت پیش‌نویس حفظ شدند. جزئیات در [گزارش حفظ فایل‌ها](preservation.json) و [گزارش پوشش داده](data-coverage.json) آمده است.

## نتیجهٔ کنترل‌ها

- `npm run verify:llm`: موفق؛ تطابق دادهٔ پایه و TypeScript، ارجاع‌ها، ادعاها و وابستگی‌های مکمل معتبرند. [خروجی اعتبارسنجی](dataset-validation.json)
- `npm test`: هر ۱۳۶ آزمون موفق؛ شامل ۲۴ آزمون ویژهٔ ارتقای داده و جلوگیری از بازگشت خطاهای قبلی.
- `npm run check`: صفر خطا و صفر هشدار.
- `npm run build`: موفق؛ نقشهٔ سایت با ۱۷۴ صفحهٔ قابل ایندکس، ۱۸۳ بلوک JSON-LD و ۲۱۰ مقصد لینک کوتاه اعتبارسنجی شد.
- مرورگر دسکتاپ و موبایل در عرض‌های ۳۲۰ و ۳۹۰ پیکسل و پوسته‌های روشن و تیره: بدون خطای اجرا و بدون سرریز افقی صفحه؛ پیمایش افقی جدول‌ها داخل کادر خودشان باقی می‌ماند.
- شمار فیلترها، پرونده و فایل‌های مدل، مقایسهٔ حافظه، هم‌زمانی، مسیر CPU و بارگذاری لایه‌ای، گروه‌بندی کارایی و محاسبات هزینه بررسی شدند. ۳۶۸ مورد نمایش تصویر محلی و ۳۸ لینک داخلی بررسی شد؛ لینک‌های بیرونی در زبانهٔ جدید باز می‌شوند.
- چهار جدول اصلی، ماتریس کاربرد و نمای اندازهٔ فایل در موبایل بررسی شدند؛ در مقادیر قابل نمایش ترکیب عدد فارسی با B یا K وجود نداشت. [گزارش مرورگر](browser-review.json) و [بررسی تکمیلی موبایل](mobile-main-review.json)

گزارش ممیزی منابعِ همراه ZIP در `data/llm/v0.3.0/research/AUDIT_FA.md` حفظ شده است؛ آمار دریافت HTTP آن گزارش متعلق به گردآوری بسته است. کنترل‌های بالا روی پروژهٔ فعلی و ساخت محلی اجرا شده‌اند.
