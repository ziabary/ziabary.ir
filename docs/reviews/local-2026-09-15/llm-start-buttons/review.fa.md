# باکس شروع فشردهٔ راهنمای LLM

لینک هر مسیر به شکل دکمه کنار توضیح سطر دوم قرار گرفت. عنوان دکمه‌ها کوتاه‌تر و فاصلهٔ عمودی ردیف‌ها کمتر شد. مقصد لینک‌ها، پنج مسیر و آمار مجموعه حفظ شده‌اند. در عرض کم، دکمه به سطر بعد منتقل می‌شود تا متن فشرده یا بریده نشود؛ حالت جمع‌شوندهٔ موبایل نیز برقرار است.

نسخهٔ محلی: http://127.0.0.1:4189/guides/llm/?show-drafts=true#start

```sh
PORT=4189 npm run preview:local
```

ارتفاع باکس در مرورگر، پس از بارگذاری فونت:

- `npm run check`: صفر خطا و صفر هشدار.
- `npm run build`: موفق، همراه اعتبارسنجی نقشهٔ سایت، داده‌های ساخت‌یافته و لینک‌های کوتاه.
- پنج دکمه و دو لینک آماری: مقصد صحیح و جدول دارای داده.
- دکمه‌ها در سه عرض دسکتاپ هم‌ردیف توضیح‌اند.
- نمایش موبایل ۳۲۰ و ۳۹۰ پیکسل، پوستهٔ روشن و تاریک، حالت باز و بسته: بدون سرریز صفحه یا بریدگی دکمه‌ها.
- خطای زمان اجرای مرورگر: صفر. [گزارش مرورگر](browser-review.json)
