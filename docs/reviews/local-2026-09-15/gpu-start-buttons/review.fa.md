# چیدمان فشردهٔ باکس شروع GPU

همان چیدمان تأییدشدهٔ LLM در باکس «از کجا شروع کنیم؟» راهنمای GPU اعمال شد: دکمه کنار توضیح سطر دوم، عنوان کوتاه دکمه، فاصله‌های عمودی کمتر و انتقال دکمه به سطر بعد هنگام کمبود عرض. سه مقصد قبلی و آمار ۸ مقالهٔ راهنما و ۲ جدول تعاملی حفظ شدند.

[بازبینی محلی](http://127.0.0.1:4189/guides/gpu-selection/)

```sh
PORT=4189 npm run preview:local
```

- `npm run check`: صفر خطا و صفر هشدار.
- `npm run build`: موفق، همراه اعتبارسنجی نقشهٔ سایت، JSON-LD و لینک‌های کوتاه.
- سه دکمه در دسکتاپ و موبایل: مقصد صحیح و باز شدن بخش‌های جمع‌شوندهٔ مقاله‌ها.
- دسکتاپ در عرض ۱۶۰۰ و ۲۱۵۶ پیکسل؛ موبایل در عرض ۳۲۰ و ۳۹۰ پیکسل؛ هر دو پوسته: موفق، بدون سرریز صفحه یا بریدگی دکمه‌ها.
- خطای زمان اجرای مرورگر: صفر. [گزارش مرورگر](browser-review.json)
