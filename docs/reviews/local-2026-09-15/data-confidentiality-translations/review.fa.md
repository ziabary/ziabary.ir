# ترجمهٔ یادداشت محرمانگی داده در APIهای عمومی

ترجمهٔ کامل انگلیسی و اسپانیایی با وضعیت `draft: false` به نسخهٔ محلی اضافه شد. تاریخ اصلی **۱۵ سپتامبر ۲۰۲۶ / ۲۴ شهریور ۱۴۰۵** و کاور WebP مشترک حفظ شدند. زمان مطالعه بر اساس طول متن، انگلیسی ۱۴ دقیقه و اسپانیایی ۱۶ دقیقه است.

هر ترجمه شامل ۶ بخش اصلی، ۱۴ زیربخش، ۲۶ بند توضیحی، یک نقل‌قول و جدول مقایسهٔ ۹ روش در ۶ ستون است. هر ۹ پیوند منبع، ترتیب مباحث، مثال‌ها و محدودیت‌های روش‌ها با متن فارسی تطبیق داده شدند. این کار ترجمهٔ مقاله است و ادعاهای منابع را به‌روزرسانی نمی‌کند.

متن و تاریخ فارسی تغییر نکرد؛ فقط `translationGroup` برای اتصال سه نسخه اضافه شد. در پیشنهاد مطالعهٔ ترجمه‌ها، دو مقالهٔ منتشرشدهٔ همان زبان دربارهٔ دسترسی غیرمستقیم به داده و کنترل‌های عملی Zero Trust AI انتخاب شدند.

[نسخهٔ انگلیسی](http://127.0.0.1:4189/en/articles/data-confidentiality-public-apis-en/) · [نسخهٔ اسپانیایی](http://127.0.0.1:4189/es/articles/data-confidentiality-public-apis-es/) · [نسخهٔ فارسی](http://127.0.0.1:4189/articles/data-confidentiality-public-apis/)

برای اجرای خروجی ساخته‌شده:

```sh
PORT=4189 npm run preview:local
```

## بررسی‌ها

- `npm run check`: صفر خطا و صفر هشدار.
- `npm run build`: موفق؛ ۱۷۴ صفحهٔ قابل‌ایندکس در نقشهٔ سایت، ۱۸۳ بلوک JSON-LD و ۲۱۰ مقصد لینک کوتاه اعتبارسنجی شدند.
- ساختار، منابع، تاریخ اصلی و کاور مشترک سه نسخه تطبیق داده شدند. [گزارش محتوا](content-review.json)
- هر دو ترجمه در آرشیو زبان خود قابل جست‌وجو هستند؛ تاریخ صفحه، آرشیو، Open Graph و JSON-LD یکسان است.
- canonical هر نسخه مستقل، hreflang سه نسخه متقابل و حضور هر سه نسخه در نقشهٔ سایت یکتا است.
- تغییر زبان فارسی ← انگلیسی ← اسپانیایی ← فارسی در مرورگر آزموده شد.
- کاور محلی، مقصد پیشنهادهای مطالعه، مقصدهای فهرست و بازشدن منابع بیرونی در برگهٔ جدید بررسی شدند.
- نمایش دسکتاپ و موبایل ۳۲۰ و ۳۹۰ پیکسل در پوستهٔ روشن و تیره بررسی شد. جدول عریض در کادر خودش پیمایش افقی دارد و صفحه سرریز ندارد؛ خطای زمان اجرا ثبت نشد. [گزارش مرورگر](browser-review.json)
