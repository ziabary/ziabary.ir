# یادداشت حفظ محرمانگی داده در استفاده از APIهای عمومی

یادداشت با شناسهٔ `data-confidentiality-public-apis`، تاریخ ۲۴ شهریور ۱۴۰۵، دستهٔ «امنیت» و زمان مطالعهٔ تقریبی ۱۴ دقیقه به نسخهٔ محلی اضافه شد. متن اصلی بدون تغییر حفظ شده است؛ عنوان ابتدای فایل به فراداده منتقل شد تا صفحه فقط یک عنوان اصلی داشته باشد. خلاصهٔ معرفی برای آرشیو و ابتدای صفحه اضافه شده است.

## شرط انتشار و لینک‌ها

متن ورودی ۹ پیوند بیرونی دارد و هیچ پیوند داخلی به مقالهٔ منتشرنشده ندارد. هر ۹ مقصد، شامل مستندات ارائه‌دهندگان و پژوهش‌های ارجاع‌شده، با مرور وب در دسترس بودند. بنابراین یادداشت `draft: false` دارد.

دو مطلب مرتبط در پایان صفحه به‌صورت دستی انتخاب شدند: «گره کور داده» و «وقتی انسان داده را نمی‌بیند». هر دو روی سایت عمومی با وضعیت HTTP 200 و صفحهٔ مقالهٔ قابل ایندکس بررسی شدند. مقاله‌های پیش‌نویس و مطالب آماده‌شده فقط در محیط محلی، در این فهرست قرار نگرفتند. ## نتیجهٔ بررسی

- `npm run check`: صفر خطا و صفر هشدار.
- `npm run build`: موفق؛ ۱۶۹ صفحه در نقشهٔ سایت، ۱۷۸ بلوک JSON-LD و ۲۰۵ مقصد لینک کوتاه اعتبارسنجی شدند.
- محتوای بدنه با فایل کاربر، پس از انتقال عنوان، دقیقاً برابر است.
- یک عنوان اصلی، canonical صحیح، نبود noindex، بارگذاری کاور محلی، ۱۲ لینک فهرست معتبر و جدول ۹ سطری با ۶ ستون بررسی شدند.
- هر ۹ پیوند مرجع با `target="_blank"` باز می‌شود.
- مقاله در آرشیو و یک‌بار در نقشهٔ سایت قرار دارد.
- نمایش جدول در موبایل ۳۲۰ و ۳۹۰ پیکسل، پوستهٔ روشن و تاریک، بدون سرریز صفحه است؛ پیمایش افقی داخل کادر جدول انجام می‌شود.
- خطای زمان اجرای مرورگر: صفر. [گزارش مرورگر](browser-review.json)
