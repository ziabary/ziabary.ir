# ورود و بازبینی دیتاست LLM — ۲۴ شهریور ۱۴۰۵

بستهٔ ۴۶فایلی `ziabary-llm-dataset-v0.1.0.zip` بررسی و به ساختار موجود متصل شد. راهنمای بسته پیش از اجرا خوانده شد؛ مسیرهای ZIP، نبود symlink، اندازهٔ فایل‌ها و هر ۴۵ checksum کنترل شدند. hash قرارداد، guide، adapter و views با مبنای بسته یکسان بود و واردکننده با کنترل hash فعال اجرا شد. مقاله‌های برنامه‌ریزی‌شده نوشته نشده‌اند؛ در این بسته متن مقاله وجود ندارد.

## نسخهٔ قابل بررسی

- صفحه: http://127.0.0.1:4188/guides/llm/?show-drafts=true
- شناسنامه: http://127.0.0.1:4188/guides/llm/?show-drafts=true&view=model-catalog#model-catalog
- نرم‌افزارها: http://127.0.0.1:4188/guides/llm/?show-drafts=true&view=software-products#serving-software
- سازگاری استقرار: http://127.0.0.1:4188/guides/llm/?show-drafts=true&view=deployment-compatibility#serving-software
- اجرا پس از ساخت: `PORT=4188 npm run preview:local`
- توسعه: `npm run dev -- --host 127.0.0.1`

شرط دقیق `show-drafts=true` برای صفحه و کارت حفظ شده است. نبود پارامتر، `false`، `1` و `TRUE` صفحهٔ پیش‌نویس را فعال نمی‌کنند. صفحه noindex است و در سایت‌مپ وارد نشده. تغییرات پیشین مقالهٔ ZTAI، فونت SVGها و لوگوهای بله و X حفظ شده‌اند. کامیت، پوش یا دیپلوی انجام نشده است.

۱۵ خانواده، ۵۹ artifact، ۱۶ رکورد API و ۹ workload در مخزن وجود دارد. هر ۷۴ ادعای قابلیت نرم‌افزار مشروط است؛ تعداد supported بدون شرط، not-supported و not-reviewed در دادهٔ واردشده صفر است. نبود رکورد، پشتیبانی یا عدم پشتیبانی محسوب نمی‌شود. ۱۰۷۳ ادعای فیلدی شامل ۶۰۸ گزارش ناشر، ۴۰۶ تحلیل تحریریه و ۵۹ محاسبه از مشخصات است. ۵۳۱ رکورد شاهد شامل ۴۷۲ گزارش ناشر و ۵۹ محاسبه است؛ این‌ها ۵۳۱ منبع مستقل نیستند و به ۲۲۱ URL یکتا ارجاع دارند.

گزارش‌های ناشر، گونه‌های کوانتیزهٔ فاقد baseRevision دقیق، ۳۰ نمرهٔ پژوهشی و ۱۳۵ بودجهٔ فرضی حجم وزن در research باقی مانده‌اند و به بنچمارک، VRAM لازم یا ROI تبدیل نشده‌اند. انتخاب سخت‌افزار از این چهار جدول خالی قابل نتیجه‌گیری نیست.

## اصلاحات اتصال و نمایش

- `src/lib/llm/data/`: بیست‌ودو ماژول TypeScript داده؛ مخزن به guide موجود متصل شد.
- `data/llm/v0.1.0/`: JSON اصلی، CSVها، پژوهش و اسناد منشأ محفوظ‌اند. راهنمای نگهداری در `data/llm/README.md` است.
- `scripts/generate-llm-dataset.py` و `scripts/validate-llm-dataset.mjs`: تولید مجدد و بررسی strict، تطبیق JSON/TS، ادعا و شاهد و جمع بایت‌ها؛ فرمان‌های `generate:llm` و `verify:llm` اضافه شدند.
- `LlmEvidence.svelte`: URL واقعی منبع، شناسه، ناشر، نوع، تاریخ، commit، locator، دامنه، محدودیت و ذی‌نفع تجاری؛ در محاسبه‌ها ورودی‌ها، منبع هر ورودی، فرمول، فرض‌ها و گردکردن قابل مشاهده‌اند. همهٔ لینک‌های بیرونی در تب جدید باز می‌شوند.
- `LlmValue.svelte` و adapters/views: note مقادیر known و شناسهٔ شاهدِ مقادیر نامعلوم حفظ شد. not-applicable و not-measured به unknown تبدیل نمی‌شوند. جزئیات پارامتر، زمینه، حجم فایل، مجوز و شروط آن نمایش دارند؛ raw و canonicalNumber حفظ شده‌اند.
- فیلتر زبان از اعلام مثبت یا ارزیابی مشخص می‌آید؛ نبود برچسب فارسی ناتوانی فارسی نیست. رکورد قابلیت بررسی‌نشده یا منفی، کاربرد مثبت برای نرم‌افزار ایجاد نمی‌کند.
- خانواده‌های SmolLM، BGE و E5 اضافه شدند؛ نسخه‌های دقیق مدل و نرم‌افزار از دادهٔ جاری ساخته می‌شوند.
- عرض بخش جزئیات تابع کادر جدول شد؛ شناسه‌های بلند می‌شکنند و اسکرول جداول در موبایل داخل کادر می‌ماند.

## بررسی‌ها

- `npm run check`: صفر خطا و صفر هشدار.
- `npm test`: ۸۱ آزمون موفق؛ دادهٔ واقعی، قرارداد، مقایسه، فیلتر و gate پوشش دارند.
- `npm run verify:llm`: تطبیق strict، JSON/TS، ارجاع‌ها، ادعای فیلدی، بایت فایل‌ها و کنترل‌های منفی موفق.
- `npm run build`: موفق؛ سایت‌مپ، دادهٔ ساختاریافته و ۲۰۴ مقصد لینک کوتاه معتبر.
- `npm run verify:local`: ۱۷۹ صفحه، صفر خطا و صفر پیوند بخش شکسته.
- `node tests/llm-guide-ui.review.mjs`: آزمون رابط هشت جدول با fixture مستقل، فیلتر، چندنتیجه‌ای بودن خانه، جزئیات، مقایسه، موبایل و تم تاریک موفق بود (سرور آزمون ۴۱۷۴).
- `node tests/llm-dataset-ui.review.mjs` و `node tests/llm-dataset-filters.review.mjs`: بازبینی دادهٔ واقعی روی پورت ۴۱۸۸.
- مرورگر واقعی: شمار ردیف‌ها، جست‌وجو، gate صفحه و کارت، جزئیات منبع و فرمول، noteها، موبایل و نبود اسکرول افقی صفحه بررسی شدند.
- فیلتر خانواده: SmolLM چهار، BGE دو و E5 یک نتیجه. فیلتر حداکثر یک میلیارد پارامتر، هفت نتیجهٔ دارای شمار معلوم می‌دهد. نسخه‌ها ۵۹ انتخاب مدل و ۱۳ انتخاب نرم‌افزار دارند. فیلترهای چهار جدول فاقد داده نتیجهٔ واقعی ندارند.
- در مقایسهٔ کاربردهای اندازه‌گیری‌نشده، نسبت، رتبه‌بندی و ادعای برتری غیرفعال ماندند.

## بررسی منابع و حدود نتیجه

تمام ۲۲۱ URL از طریق درخواست HTTP بررسی شدند و پس از یک بازبینی مجدد، پاسخ موفق داشتند. هفت پاسخ اولیهٔ ۴۲۹ موقت بودند. این کنترل، تأیید محتوای همهٔ ۱۰۷۳ ادعا نیست.

برای Qwen3-8B، BGE-M3، SmolLM2-135M-Instruct و Gemma 4 E2B، متادیتای رسمی در همان commit دریافت شد؛ revision و اندازهٔ تک‌تک فایل‌های منتخب با دادهٔ بسته تطبیق داشت. هیچ وزن مدلی دانلود یا روی GPU اجرا نشد. کیفیت فارسی، عملکرد سرویس و مجوز حقوقی استفادهٔ خاص به‌طور مستقل تأیید نشده‌اند.
