# اصلاح مسیرهای شروع راهنمای GPU

کارت «پیش از خرید، سازگاری را بررسی می‌کنم» از باکس شروع حذف و دو مسیر جایگزین شد:

- **کارت گیمینگ برای هوش مصنوعی کافی است؟** — تفاوت کارت‌های گیمینگ، حرفه‌ای و دیتاسنتری؛ از کجا شروع کنیم؟ دکمهٔ «شناخت انواع GPU» به بخش `gpu-types-for-ai` می‌رود.
- **چه چیزی GPU قدرتمند شما را معطل می‌کند؟** — نقش CPU، رم، ذخیره‌سازی و شبکه در سرعت پردازش. دکمهٔ «شناخت اجزای سرور» به بخش `gpu-server-platform-components` می‌رود.

دو مسیر نخست حفظ شدند. باکس اکنون چهار مسیر دارد و همان چیدمان فشرده با دکمه کنار توضیح، آمار مجموعه و حالت جمع‌شوندهٔ موبایل را به کار می‌برد.

[بازبینی محلی](http://127.0.0.1:4189/guides/gpu-selection/)

```sh
PORT=4189 npm run preview:local
```

`npm run check` با صفر خطا و هشدار و `npm run build` با موفقیت انجام شدند. چهار مقصد در مرورگر آزموده شدند و بخش‌های جمع‌شوندهٔ مربوط باز می‌شوند. دسکتاپ ۱۶۰۰/۲۱۵۶ و موبایل ۳۲۰/۳۹۰ پیکسل، پوستهٔ روشن و تاریک، بدون سرریز صفحه یا خطای زمان اجرا بررسی شدند.
