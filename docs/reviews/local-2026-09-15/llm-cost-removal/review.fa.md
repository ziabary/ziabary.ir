# حذف بخش اجاره و محاسبات هزینه از راهنمای LLM

درخواست: حذف کامل جدول «هزینهٔ اجاره و سناریوهای پردازش» و همهٔ داده‌های وابسته، روی نسخهٔ فعلی پروژه.

تغییرات انجام‌شده:

- جدول اجاره، محاسبه‌گر هزینهٔ توکن و محاسبه‌گر خرید در برابر اجاره حذف شدند.
- ۱۶ نرخ اجاره، ۱۶ ردیف محاسبات اقتصادی و ۲۰ مثال هزینهٔ توکن، همراه با سه فایل دادهٔ مربوط حذف شدند.
- مدل داده، ماژول تولیدشده، توابع محاسبه و تنظیمات فیلتر و مقایسهٔ هزینه حذف شدند.
- منبع اختصاصی قیمت RunPod و لوگوهای بلااستفادهٔ RunPod و Trooper حذف شدند. منبع Trooper برای مشخصات ظرفیت حافظهٔ RTX 4090 اصلاح‌شده، که هنوز در جدول حافظه استفاده می‌شود، حفظ شد.
- مسیر شروع مربوط به هزینه و ورودی منوی آن حذف شدند. راهنما اکنون ۴ مسیر شروع، ۶ بخش و ۷ جدول تعاملی دارد.
- فهرست وابستگی‌ها و هش‌ها، مستندات فعال و آزمون‌های بخش حذف‌شده به‌روزرسانی شدند.

مقایسه با پشتیبان قبل از همین تغییر نشان داد تمام داده‌های پایه، جز مجموعهٔ خالی هزینه که حذف شد، دقیقاً یکسان‌اند. فایل‌های حافظه و کارایی نیز تغییری نکرده‌اند. ۸۷ مدل، ۱۱۰۱ نتیجهٔ کیفیت، ۴۰ اجرای منتشرشده و داده‌های کوانت و مسیرهای اجرا حفظ شدند. یادداشت‌های مستقل نقشهٔ نگارش دست‌نخورده‌اند.

نتیجهٔ بررسی:

- `npm run check`: صفر خطا و صفر هشدار.
- `npm run build`: موفق؛ ۱۷۴ نشانی نقشهٔ سایت، ۱۸۳ بلوک JSON-LD و ۲۱۰ لینک کوتاه معتبر.
- `npm test`: هر ۱۴۳ آزمون موفق؛ صفر شکست و صفر آزمون ردشده یا اجرا‌نشده. دو آزمون مخصوص محاسبه‌گرهای حذف‌شده نیز حذف شدند.
- `npm run verify:llm`: تطابق دادهٔ JSON و TypeScript، روابط و شواهد و هش وابستگی‌ها معتبر.
- اعتبارسنج مکمل: ۱۸٬۴۳۰ کنترل موفق.
- بازبینی مرورگر: حذف کامل جدول و محاسبه‌گرها، مقصدهای معتبر منو، سلامت فیلترها و پنل مدل، بارگیری ۳۳۶ تصویر محلی و بررسی ۳۵ پیوند داخلی؛ بدون خطای زمان اجرا.
- دسکتاپ ۱۶۰۰ و موبایل ۳۹۰ و ۳۲۰ پیکسل، پوستهٔ روشن و تیره بررسی شدند؛ پیمایش افقی داخل جدول‌ها محدود می‌ماند.
- در فایل‌های جاوااسکریپت ساخت نهایی، اثری از RunPod و عنوان یا کنترل‌های ابزار هزینه باقی نمانده است.
