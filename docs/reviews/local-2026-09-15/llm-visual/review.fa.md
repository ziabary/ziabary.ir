تغییرات قابل مشاهده

- انتخاب ستون با الگوی GPU هماهنگ شد: × کنار عنوان، ستون را پنهان می‌کند؛ دکمه‌های بالای جدول آن را برمی‌گردانند. «چیدمان پیش‌فرض» انتخاب‌ها را بازنشانی می‌کند. ستون‌های ماتریس کاربرد هم قابل پنهان‌کردن‌اند. انتخاب ستون با جست‌وجو و فیلتر تغییر نمی‌کند؛ ستون خالیِ اختیاری همچنان قابل نمایش است.
- کنترل ستون دوم یک فلش SVG با نام دسترس‌پذیر «منابع و جزئیات» است. متن بلند دیگر داخل دکمهٔ باریک نمی‌شکند. این آیکون به Font Awesome یا شبکه وابسته نیست.
- شرح کاربرد از داخل خانهٔ باریک به یک ردیف بازشونده، هم‌عرض قاب جدول، منتقل شد. منبع، دلیل، شرایط و نتیجهٔ آزمون در آن دیده می‌شوند؛ ارتفاع خود ردیف مدل با بازشدن شرح ثابت می‌ماند. در آزمون BGE-M3، ارتفاع ردیف قبل و بعد ۷۵ پیکسل و عرض شرح ۱۱۶۹ پیکسل در قاب ۱۱۷۱ پیکسلی بود.
- اندازهٔ پارامترها با «میلیارد» نوشته می‌شود؛ برای نمونه «حدود ۸٫۲ میلیارد». نام فنی `Qwen3-8B` حفظ شده است. عدد مستند پارامترها، عدد داخل نام مدل و مقدار خام فیلتر با هم جایگزین نشده‌اند.
- «کاربرد مستند» به «سازنده این کاربرد را ذکر کرده» تغییر کرد. برای شرح‌های اختصاصی، «طبق معرفی سازنده» یا برچسب هدف تخصصیِ دارای شاهد نمایش داده می‌شود. توضیح بالای ماتریس روشن می‌کند که معرفی سازنده، تضمین کیفیت یا آزمون فارسی نیست.
- عنوان مجموعه به «راهنمای انتخاب مدل زبانی» کوتاه شد. کارت LLM در دسکتاپ مانند GPU تمام عرض ردیف را می‌گیرد؛ در موبایل در همان جریان تک‌ستونی کارت‌ها قرار می‌گیرد.
- تصویر موجود `/images/guides/llm.png` به ابتدای راهنما اضافه شد؛ نسخه‌های WebP پاسخ‌گو از مسیر تصاویر پروژه استفاده می‌شوند. تصویر جدیدی تولید یا جایگزین نشده است.

انتخاب مقاله‌ها

مقاله‌های برنامه‌ریزی‌شده زیر هر جدول، با برچسب «در برنامهٔ نگارش»، در اولویت هستند. پیوند آن‌ها به عنوان مربوط در نقشهٔ نگارش همین صفحه می‌رود؛ مسیر مقالهٔ نوشته‌نشده ساخته نشده است.

| جدول | موضوع‌های منتخب در برنامهٔ نگارش |
|---|---|
| شناسنامه | پارامتر کل و فعال؛ اندازهٔ مناسب مدل؛ مجوزها |
| کاربردها | اندازهٔ مناسب؛ انتخاب مدل و embedding و reranker برای RAG؛ نیازهای برنامه‌نویسی؛ ارزیابی فارسی |
| نرم‌افزارها | انتخاب Ollama/vLLM/SGLang/llama.cpp؛ نقش مدل، موتور، API و رابط؛ تبدیل اجرای تک‌کاربره به سرویس |
| تخصصی | انتخاب embedding و reranker برای RAG؛ اندازهٔ مناسب مدل؛ ارزیابی فارسی |

خبر به‌روزرسانی ترگمان و پیوندهای کلیِ نامرتبط از انتخاب‌های جدول‌ها کنار گذاشته شدند. زیر ماتریس کاربرد و مدل‌های تخصصی، مقالهٔ منتشرشدهٔ کم‌ارتباط تحمیل نشده است. در بخش‌های دیگر فقط مطالبی باقی مانده‌اند که مفهوم مشخصی مانند حافظهٔ وزن، پشتیبانی کرنل، ظرفیت سرویس یا سنجه‌های تأخیر را توضیح می‌دهند. نگاشت‌ها دستی‌اند و ترتیب مطالب در frontmatter مقاله‌های سایت تغییر نکرده است.

آزمون‌ها

- `npm run check`: صفر خطا و صفر هشدار. [خروجی](check.log)
- `npm test`: ۹۸ آزمون موفق؛ صفر شکست. [خروجی](tests.log) آزمون‌های ارتباط نقشهٔ نگارش و حفظ مقدار عددی هنگام تغییر نمایش پارامتر اضافه شده‌اند.
- `npm run build`: موفق؛ ۱۶۸ آدرس sitemap، ۱۷۷ بلوک JSON-LD و ۲۰۴ مقصد لینک کوتاه اعتبارسنجی شدند.
- `npm run verify:local`: ۱۷۹ صفحه، صفر خطا و صفر مشکل fragment.
- `npm run verify:llm`: موفق؛ همان ۵۹ مدل، ۱۳ نرم‌افزار، ۱۳۶ کاربرد و ۳۷ نتیجهٔ منتشرشده حفظ شده‌اند. [گزارش داده](dataset-validation.json)
- آزمون بصری: حذف و بازگردانی ستون در هر چهار جدول، پایداری انتخاب پس از فیلتر، شرح عریض، اندازهٔ آیکون، بارگذاری تصویر، عرض کارت و اعتبار پیوندهای نقشهٔ نگارش موفق بود. در هشت حالت موبایل (چهار جدول × دو پوسته) عرض صفحه از نمایشگر بیشتر نشد. [گزارش مرورگر](browser-review.json)
- آزمون پذیرش: gate صفحه و کارت، امتیازهای ناشر، کپی کامل revision و ستون خالی اختیاری بررسی شد. [گزارش پذیرش](browser-acceptance.json)

- آزمون مرورگر هر هشت نما با دادهٔ مصنوعی نیز موفق بود؛ نمایش جزئیات سخت‌افزار، مقایسه و اسکرول موبایل حفظ شده‌اند. [خروجی](fixture-browser.log)

هر ۱۴ مقاله همچنان `planned` است. صفحه و کارت فقط با مقدار دقیق `show-drafts=true` نمایش داده می‌شوند؛ راهنما عمومی یا وارد sitemap نشده است.
