# تاریخ آخرین به‌روزرسانی جدول‌های LLM

در کارت «از کجا شروع کنیم؟»، عبارت «به‌روزرسانی پیوسته» با تاریخ واقعی داده‌ها جایگزین شد:

**آخرین به‌روزرسانی داده‌ها: ۲۴ شهریور ۱۴۰۵**

تاریخ از `llmDatasetUpdatedOn` در ماژول تولیدشدهٔ داده‌ها می‌آید که مبنای آن `asOf` در `data/llm/v0.3.0/manifest.json` است. نمایش شمسی و اعداد فارسی با تابع مشترک قالب‌بندی تاریخ سایت انجام می‌شود؛ مقدار استاندارد `2026-09-15` نیز در عنصر `time` قرار دارد. زمان ساخت سایت روی تاریخ اثر ندارد.

تاریخ در سطری زیر آمار مدل‌ها، نرم‌افزارها و جدول‌ها آمده و در موبایل امکان شکستن سطر بدون شکستن خود تاریخ را دارد. تنها `LlmGuidePage.svelte` برای این تغییر ویرایش شد؛ سایر تغییرات قبلی حفظ شدند.

اجرا و بازبینی:

```bash
npm run build
PORT=4189 npm run preview:local
```

[کارت ابتدایی راهنما](http://127.0.0.1:4189/guides/llm/?show-drafts=true#start)

- `npm run check`: صفر خطا و صفر هشدار.
- `npm run build`: موفق؛ ۱۷۴ نشانی نقشهٔ سایت، ۱۸۳ بلوک دادهٔ ساخت‌یافته و ۲۱۰ لینک کوتاه معتبر.
- `git diff --check`: موفق.
- مرورگر: تاریخ و مقدار استاندارد آن، RTL، آمار موجود و نبود سرریز در عرض‌های ۱۴۴۰، ۳۹۰ و ۳۲۰ پیکسل، پوستهٔ روشن و تیره بررسی شدند. [گزارش مرورگر](browser-review.json)
