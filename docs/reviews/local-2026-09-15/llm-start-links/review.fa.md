# بازبینی باکس شروع راهنمای LLM

باکس «از کجا شروع کنیم؟» بر اساس ظاهر راهنمای GPU اصلاح شد: مقدمهٔ کوتاه، عنوان و توضیح هر مسیر، لینک مستقل زیر توضیح، فاصله‌گذاری و جداکننده‌های مشابه GPU و آمار مجموعه در پایین باکس.

آمار از داده‌های جاری محاسبه می‌شود: ۵۹ مدل، ۱۳ نرم‌افزار و ۸ جدول تعاملی. شمار مدل و نرم‌افزار به جدول مربوط لینک دارد. پنج مسیر قبلی و حالت جمع‌شوندهٔ موبایل حفظ شدند.

بازبینی محلی: http://127.0.0.1:4189/guides/llm/?show-drafts=true#start

فرمان اجرا از ریشهٔ ریپو:

```sh
PORT=4189 npm run preview:local
```

## نتیجهٔ بررسی

- `npm run check`: صفر خطا و صفر هشدار.
- `npm run build`: موفق؛ اعتبارسنجی ۱۶۸ صفحهٔ نقشهٔ سایت، ۱۷۷ بلوک JSON-LD و ۲۰۴ لینک کوتاه.
- هر پنج لینک مسیر شروع و هر دو لینک آماری در مرورگر آزموده شدند؛ مقصد درست و جدول دارای داده است.
- دسکتاپ با عرض ۱۱۰۰ و ۱۶۰۰؛ موبایل با عرض ۳۲۰ و ۳۹۰؛ پوستهٔ روشن و تاریک؛ باز و بسته شدن مسیرهای موبایل: موفق، بدون سرریز صفحه.
- خطای زمان اجرای مرورگر: صفر. [گزارش مرورگر](browser-review.json)
