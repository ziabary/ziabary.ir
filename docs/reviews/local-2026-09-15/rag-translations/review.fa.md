# ترجمهٔ انگلیسی و اسپانیایی یادداشت RAG، CAG، KAG و تنظیم مدل

دو ترجمهٔ کامل با وضعیت `draft: false` به نسخهٔ محلی اضافه شدند. تاریخ اصلی **۱۵ ژوئن ۲۰۲۶ / ۲۵ خرداد ۱۴۰۵** حفظ شد؛ تاریخ نمایشی انگلیسی «15 June 2026» و اسپانیایی «15 de junio de 2026» است. کاور WebP هر سه نسخه مشترک است و فایل تکراری ساخته نشد.

هر ترجمه شامل ۱۲ بخش، ۳۱ بند توضیحی، جدول ۵×۵، پنج سناریوی عملی، پنج سوءبرداشت و شش منبع اصلی است. مثال‌های حشره‌شناس و پزشک، محدودیت‌های روش‌ها و تمایز افزودن دانش از تغییر پارامترها حفظ شدند. زمان مطالعه بر اساس طول ترجمه‌ها، انگلیسی ۱۷ و اسپانیایی ۱۹ دقیقه برآورد شد. پیشنهادهای مطالعهٔ هر نسخه به مقاله‌های همان زبان متصل‌اند.

نسخهٔ فارسی فقط یک `translationGroup` دریافت کرد؛ متن و تاریخ آن تغییر نکرد. این گروه، تغییر زبان و hreflang متقابل سه نسخه را فعال می‌کند.

[نسخهٔ انگلیسی](http://127.0.0.1:4189/en/articles/rag-cag-kag-fine-tuning-instruction-tuning-en/) · [نسخهٔ اسپانیایی](http://127.0.0.1:4189/es/articles/rag-cag-kag-fine-tuning-instruction-tuning-es/)

```sh
PORT=4189 npm run preview:local
```

## نتیجهٔ بررسی

- `npm run check`: صفر خطا و صفر هشدار.
- `npm run build`: موفق؛ ۱۷۲ صفحهٔ نقشهٔ سایت، ۱۸۱ بلوک JSON-LD و ۲۰۸ مقصد لینک کوتاه اعتبارسنجی شدند.
- ساختار هر دو ترجمه و تمام ۱۲ پیوند به شش منبع با نسخهٔ فارسی تطبیق داده شد. [گزارش محتوا](content-review.json)
- تاریخ در صفحه، آرشیو، Open Graph و JSON-LD یکسان است؛ canonical هر نسخه مستقل و hreflang سه نسخه متقابل است.
- تغییر زبان فارسی ← انگلیسی ← اسپانیایی ← فارسی در مرورگر آزموده شد.
- هر ترجمه در آرشیو زبان خود قابل جست‌وجو است و هر سه نسخه یک بار در نقشهٔ سایت حضور دارند.
- کاور محلی، پیشنهادهای مطالعه، فهرست مقاله و جدول در دسکتاپ و موبایل ۳۲۰/۳۹۰ پیکسل و هر دو پوسته بررسی شدند؛ سرریز صفحه یا خطای زمان اجرا مشاهده نشد.
- [گزارش مرورگر](browser-review.json)
