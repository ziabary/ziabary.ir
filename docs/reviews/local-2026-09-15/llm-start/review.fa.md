# جایگزینی باکس ورودی راهنمای LLM

باکس معرفی و آمار حذف شد. پنج مسیر «از کجا شروع کنیم؟» با متن کوتاه‌تر و فهرست شماره‌دار، مانند GPU کنار کاور قرار گرفتند. بخش تکراری مسیرهای شروع در پایین تصویر نیز حذف شد. در موبایل، مسیرها زیر تصویر و در یک بخش بازشونده هستند. تغییرات پیشین حفظ شدند و انتشار عمومی انجام نشده است.

[نسخهٔ محلی](http://127.0.0.1:4189/guides/llm/?show-drafts=true#start)

- `npm run check`: صفر خطا و صفر هشدار.
- `npm run build`: موفق؛ sitemap، دادهٔ ساختاریافته و لینک‌های کوتاه معتبر.
- بررسی مرورگر در عرض‌های ۱۶۰۰، ۳۹۰ و ۳۲۰ پیکسل: بدون بیرون‌زدگی، فقط یک باکس شروع، پنج مقصد معتبر با حفظ پیش‌نویس و preset، بازشدن بخش موبایل با Enter و صفر خطای runtime.
- `git diff --check`: موفق.
