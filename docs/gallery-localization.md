# ترجمه و انتشار گالری

داده‌های هر سه زبان در `src/lib/gallery.ts` نگهداری می‌شوند. عنوان، کپشن،
تاریخ و تصاویر فارسی همچنان در فیلدهای فعلی قرار دارند.

برای هر آلبوم، عنوان و معرفی انگلیسی و اسپانیایی را در
`translations.en` و `translations.es` با کلیدهای `title` و `caption` بنویسید.
برای **هر عکس** نیز ترجمهٔ کپشن را کنار همان عکس قرار دهید:

```ts
{
  src: '/images/gallery/example.jpg',
  alt: 'توضیح فارسی تصویر',
  caption: 'کپشن فارسی',
  translations: {
    en: { caption: 'English caption', alt: 'English image description' },
    es: { caption: 'Pie de foto en español', alt: 'Descripción de la imagen' }
  }
}
```

- وجود کپشن غیرخالی برای هر عکس، انتشار آن عکس را در زبان مربوط فعال می‌کند.
- حذف ترجمه یا خالی‌کردن `caption`، عکس را فقط از همان زبان حذف می‌کند؛ حتی از نمایشگر و بندانگشتی‌های آلبوم.
- ترجمهٔ عنوان و معرفی آلبوم به‌تنهایی باعث انتشار عکس‌ها نمی‌شود.
- اگر هیچ عکس واجد شرایطی باقی نماند، آلبوم هم در آن زبان نمایش داده نمی‌شود.
- اولین عکس واجد شرایط، کاور آلبوم خواهد بود.
- `alt` اختیاری است؛ در نبود آن، کپشن همان زبان استفاده می‌شود. اگر عنوان یا معرفی ترجمه‌شدهٔ آلبوم موجود نباشد، کپشن اولین عکس واجد شرایط جایگزین می‌شود.
- متن فارسی یا زبان دیگر هیچ‌گاه جایگزین ترجمهٔ مفقود نمی‌شود. ترتیب آلبوم‌ها و عکس‌ها حفظ می‌شود.

دو تب نوشته‌ها و گفتگوها، و گفتگوهای صوتی و تصویری در صفحات انگلیسی و
اسپانیایی فعلاً خالی هستند. افزودن مصاحبهٔ واقعی به این زبان‌ها یک تغییر
محتوایی مستقل است و از ترجمهٔ محتوای فارسی یا گالری تغذیه نمی‌شود.

بررسی منطق انتشار: `node tests/gallery-locales.test.mjs`
