# پیش‌نویس INT8 و FP8

- نمودار اصلی SVG و PNG، همراه CSV، در `static/images/articles/int8-or-fp8-real-gpu-support/` نگهداری می‌شود. کاور SVG شماتیک جدید است؛ نمودار نسبت نرخ‌ها بدون تغییر داده حفظ شده است.

- ادعاهای نرم‌افزاری، یافته‌های نسخه‌های مشخص در پژوهش اوت ۲۰۲۶ هستند؛ بنچمارک تازه یا ممیزی همهٔ نسخه‌های فعلی انجام نشده است.
- لینک‌های داخلی در متن و فهرست `related` ثبت شده‌اند. فهرست‌های دستی مقالات قبلی تغییر نکرده‌اند تا لینک عمومی به صفحهٔ پیش‌نویس ایجاد نشود.
