# راهنمای مطالعهٔ GPU — ۲۵ شهریور ۱۴۰۵

طبق بازخورد صاحب سایت، ورودی فارسی راهنمای GPU به مقدمهٔ سه‌پاراگرافی دربارهٔ بار کاری و خانواده‌های GPU و جدول دو‌ستونی شش‌ردیفی تبدیل شد. تصویر اصلی حفظ شد. جدول پیشنهاد کارت‌ها، کادر تجربهٔ ترگمان و مسیرهای قبلی «از کجا شروع کنیم؟» با این ورودی جایگزین شدند.

جدول راهنما نُه لینک به شناسه‌های موجود مقاله‌ها و جدول‌ها دارد. هر لینک مقالهٔ بسته را باز می‌کند؛ برای کلیک دوباره روی همان نشانی نیز بازشدن تضمین می‌شود. شناسهٔ gpu-quick-selection برای راهنمای مطالعه و gpu-in-practice برای مقدمه حفظ شده‌اند تا نشانی‌های قبلی به بخش مرتبط برسند. فاصلهٔ پرش از سربرگ ثابت ۱۱۰ پیکسل است.

ارجاع تجربهٔ ترگمان در مقالهٔ gpu-inference-latency-throughput باقی است. مشخصات کارت‌ها، تاریخ بازبینی جدول جامع، مقالات و ترتیب مجموعه تغییر نکرده‌اند. عنوان و توضیحات متای بازبینی قبلی حفظ شده‌اند.

بازبینی قبلی در ../gpu-quick-selection/2026-09-16.md مربوط به طراحی کنارگذاشته‌شده است؛ تصاویر آن آرشیو نسخهٔ قبلی هستند.

اعتبارسنجی نهایی: npm run check بدون خطا و هشدار؛ npm run build موفق، همراه اعتبارسنجی sitemap، دادهٔ ساختاریافته و لینک‌های کوتاه. آزمون مرورگر tests/gpu-reading-guide.review.mjs همهٔ نُه مقصد، بازکردن دوبارهٔ مقالهٔ بسته، ورود مستقیم با fragment و نبود تداخل تیتر با سربرگ را تأیید کرد. جدول در عرض‌های ۳۲۰، ۳۹۰، ۷۶۸ و ۱۶۰۰ پیکسل دو‌ستونی و بدون اسکرول افقی است؛ تم روشن و تیره بررسی شدند. برای پرش دقیق پس از بازشدن مقاله از اسکرول مستقیم استفاده شد تا انیمیشن طولانی میان مقاله‌های باز مقصد را جابه‌جا نکند.
