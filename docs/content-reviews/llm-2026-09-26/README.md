# بازبینی محلی اطلس و بازیابی سازمانی — ۲۰۲۶-۰۹-۲۶

دامنهٔ کار، ویرایش و اعتبارسنجی محلی بود. deploy، انتشار عمومی، merge، خرید سرویس یا اجرای بنچمارک انجام نشده است. تغییرات قبلی کاربر، از جمله مقاله و تصویر «قرارداد هوش مصنوعی»، حفظ شدند.

## داده‌ها و شناسه‌ها

منبع اصلی `data/llm/v0.3.0/repository.json` است؛ فایل‌های `src/lib/llm/data/*.v1.ts` فقط با `npm run generate:llm` تولید شدند. هیچ importer تاریخی بازاجرا نشد.

`preservation.json` مقایسه با HEAD را ثبت می‌کند: همهٔ رکوردهای قبلی مدل و داده‌های مکمل حفظ شده‌اند. رکورد موجود LFM2.5-1.2B-Instruct از قبل مجوز restricted داشت و تغییر نکرد. SGLang 0.5.20، شرایط CUDA آن، llama.cpp 0.5.0، RPC و متن b11160 باقی مانده‌اند؛ رکورد جدید یا پیش‌فرض اجرایی برای b11182 ساخته نشده است. هیچ مدل، embedding، موتور یا دستهٔ تازه‌ای برای Compass ساخته نشد.

## شواهد تأییدشده و محدودیت‌ها

[آرشیو منابع](../../../data/llm/sources/decision-runtime-2026-09-26/README.md) شامل URL، تاریخ دسترسی، revision و SHA-256 است. مدل‌کارت‌ها، LICENSEها و configها مجدداً از revision دقیق دریافت و hash آن‌ها با capture نخست تطبیق داده شد. سه فایل مجوز جداگانه بررسی شدند؛ استفادهٔ تجاری به سقف درآمد سالانه و بندهای ۱ و ۵ وابسته است، تعریف Legal Entity و افراد حفظ شده و استثنای مؤسسهٔ غیرانتفاعی واجد شرایط به کاربرد غیرتجاری/پژوهشی محدود مانده است. دربارهٔ مرز دقیقاً ۱۰ میلیون دلار حکم تازه‌ای داده نشده است.

مدل‌کارت DSpark حداقل SGLang 0.5.19 و MLX-VLM 0.7.2 را مستند می‌کند. مسیر GGUF رسمی llama.cpp مستند است، اما حداقل build آن مشخص نشده؛ این وضعیت «پشتیبانی نمی‌شود» نیست. GGUF F16 به‌عنوان قالب و دقت ثبت شده و شاهد کوانتیزاسیون نیست. حافظهٔ کامل ترکیب هدف، بینایی، مکمل، cache و runtime، کیفیت فارسی و نتیجهٔ RTX 4090 همچنان نامعلوم/اندازه‌گیری‌نشده‌اند.

شتاب‌های انتها‌به‌انتها صرفاً گزارش ناشرند: H100 80GB/SGLang/BF16 برابر 1.64–2.27× با block=9؛ M5 Max/MLX-VLM/FP16 برابر 1.56–2.62× و M3 Ultra/llama.cpp/FP16 برابر 1.30–1.77× با block=8. batch=1، temperature=0، شش وظیفه و سقف خروجی Apple برابر ۲۰۴۸ توکن حفظ شدند. نسخهٔ دقیق موتورهای بنچمارک و revision وزن‌های ارزیابی‌شده معلوم نیست؛ حداقل نسخهٔ پشتیبانی جای آن‌ها ننشسته است. این ردیف‌ها وارد کیفیت، tok/s، TTFT، نتیجهٔ فارسی، کوانتیزاسیون یا هم‌زمانی نشده‌اند و مقایسهٔ محاسباتی بدون پروتکل مشترک مجاز نشده است.

API رسمی GitHub برای b11182 مقدار `prerelease=true` و انتشار ۲۰۲۶-۰۹-۲۵ را نشان داد. commit `e9f824d8c0f011662a742c9d15d4aa18a41e32c0` سیاست metadata، مسیر CUDA/Blackwell برای NVFP4/MXFP4، W4A8 در لایه‌های W4A16 و مقادیر auto/q4/q8 را مستند می‌کند. q4 توصیهٔ پیش‌فرض نشده و ادعای سرعت یا حافظه برای کارت‌های دیگر ساخته نشده است.

شش درخواست صفحات زندهٔ LLM و GPU در fa/en/es همگی HTTP 504 دریافت کردند؛ بنابراین نتیجهٔ مشاهدهٔ آنلاین صفحه ادعا نمی‌شود. بررسی محتوا و تعامل روی build محلی در هر سه زبان انجام شد؛ جزئیات در `browser.json` ثبت شده است.

## فایل‌های محتوا و رابط

- `src/lib/content/articles/rag-retrieval-access-control-compass.md`: پیش‌نویس فارسی با `draft: true`، ارجاعات درون متن، مسئلهٔ مجوز هنگام بازیابی، multihop/cache/reranking/context، تفکیک Cloud و self-hosted و مرز MCP. HighFinance با افزایش ۱۶٫۳ واحد در مقیاس نمایش‌داده‌شده، داخلی‌بودن و تفاوت parsing توضیح داده شد. قیمت، SLA، اقامت داده یا امکان خدمت به ایران قطعی نشده است.
- `docs/experiments/dspark-retrieval-2026-09-26.md`: طرح RTX 4090 و retrieval؛ تمام نتایج «اجرا نشده»، بدون راه‌اندازی سرویس یا ارسال دادهٔ محرمانه.
- `src/lib/llm/schema.ts`، `adapters.ts` و `wizard-candidates.ts`: وابستگی صریح، نمایش آن، اعتبارسنجی مرجع و جلوگیری از پیشنهاد مستقل/تخمین حافظهٔ مکمل.
- `src/lib/llm/research-views.ts` و مکمل‌های `published-performance.json`/`sources.json`: نمایش شتاب نسبی در مسیر موجود شواهد عملکرد؛ ترجمه‌ها و bindingها در `data/llm/locales/`.
- `src/lib/components/LlmModelProfile.svelte`: نمایش مجوز و شرایط آن در هر سه زبان؛ فیلتر commercial-use کاتالوگ فارسی نیز فعال شد. سیاست عمومی پرسش‌های مجوز ویزارد فارسی تغییر نکرد؛ DSpark در همهٔ زبان‌ها مستقلاً حذف می‌شود.
- `src/lib/components/GpuPrecisionNote.svelte` و اتصال آن در `GuidePage.svelte` و `GpuReview.svelte`: یادداشت منبع‌دار وزن/فعال‌سازی/موتور/سخت‌افزار در هر سه راهنمای GPU.
- `src/lib/guide-updates.mjs`: دو اعلان با شناسهٔ پایدار؛ فهرست‌های related و ترجمه‌های مقاله‌ها دست‌کاری نشدند.

`src/lib/gpu-data.ts` و `src/lib/server-data.ts` با HEAD یکسان‌اند؛ hash هر دو در گزارش حفظ داده ثبت شده است. اعداد حافظه، توان، TFLOPS و سازگاری OEM/سرور تغییر نکرده‌اند.

## اعتبارسنجی

`npm run generate:llm`، `npm run verify:llm`، `npm run check`، `npm test` و `npm run build` اجرا شدند. همهٔ فرمان‌ها موفق شدند: check با صفر خطا و هشدار؛ ۲۶۱ آزمون موفق؛ sitemap با ۲۰۶ صفحهٔ indexable و ۲۳۵ فایل HTML بررسی شد. مرورگر در هر سه زبان بدون exception، با ۱۸ ردیف شتاب نسبی و نمایش درست وابستگی/مجوز بررسی شد. عرض سند در موبایل ۳۹۰ پیکسل بود و سرریز افقی نداشت؛ پیش‌نویس noindex و خارج از sitemap است. جزئیات در `validation.json` و `browser.json` ثبت شده‌اند. بررسی مرورگر با `node scripts/review-llm-sept26.mjs` قابل تکرار است؛ مبدأ پیش‌فرض محلی پورت 4186 و مرورگر CDP روی پورت 9334 است.

آزمون رفتاری `tests/llm-dependencies-20260926.test.mjs` مکمل را حتی با kind و کاربرد ظاهراً مجاز از نامزدها حذف می‌کند، فراخوانی‌نشدن تخمین حافظه را می‌سنجد، مرجع وابستگی خراب را رد می‌کند، فیلتر واقعی مجوز را در سه زبان بررسی می‌کند و جدایی سرعت نسبی/کیفیت/TTFT و نبود پیش‌انتشار در پیشنهادهای اجرایی را می‌سنجد. انتظارهای عددی آزمون‌های قبلی با دو مدل، سه بسته و ۱۸ مشاهدهٔ جدید به‌روز شدند؛ دو انتظار قدیمی تعداد نرم‌افزار و تاریخ بازبینی Ollama نیز با وضعیت موجود مخزن تطبیق داده شدند. هیچ آزمونی حذف یا برای پذیرش نتیجهٔ علمی نادرست ضعیف نشد.
