# بستهٔ یادداشت زیرساخت انسانی هوش مصنوعی

نسخهٔ بازبینی‌شده در ۱ اکتبر ۲۰۲۶.

- `ai-talent-infrastructure-fa.md`: متن کامل فارسی، با ارجاع پانویس و مسیر نسبی تصاویر.
- `images/`: ۹ نمودار؛ هرکدام در دو قالب SVG و PNG. تصویر کاور تزئینی ساخته نشده است.
- `data/`: داده‌های هر نمودار، محاسبات و فهرست منابع.
- `editorial-review.md`: تغییرات نسبت به نسخهٔ قبلی و محدودیت‌های بررسی.

برای نمایش تصاویر، فایل Markdown را کنار پوشهٔ images نگه دارید. اگر موتور سایت SVG را نمایش نمی‌دهد، پسوند مسیر تصویر را از svg به png تغییر دهید. SVGها فونت را به مسیر تبدیل کرده‌اند و برای نمایش به نصب فونت وابسته نیستند. داده و نمودارها بازترسیم مستقل‌اند؛ PDF کامل ناشران در بسته بازتوزیع نشده است.

این بسته روی سایت منتشر یا اعمال نشده است.
