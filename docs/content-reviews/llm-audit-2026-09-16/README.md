### نمونهٔ محاسبهٔ اصلاح‌شده

Qwen2.5-Coder-32B-Instruct Q4_K_M: فایل **۱۹٬۸۵۱٬۳۳۵٬۸۷۲ بایت**، حدود **۱۸٫۴۹ GiB**. با زمینهٔ ۸٬۱۹۲، یک درخواست، KV از نوع FP16 و ذخیرهٔ اجرایی ۲ GiB، بودجه حدود **۲۲٫۴۹ GiB** است؛ محاسبهٔ ظرفیت است، نه نتیجهٔ سرعت یا کیفیت.

ایران‌سرور Smart با فرض تکرار تعرفه و تخفیف سالانه در سال دوم: `91,000,000 × 0.9 × 24 = 1,965,600,000` تومان. اختلاف با سبد خرید موجود `684,500,000` و متوسط ماهانه `28,520,833` تومان است. این سناریو تضمین تعرفهٔ سال آینده نیست.

## مواردی که به نتیجهٔ ساختگی تبدیل نشدند

- HW-04/07/08/09، SC-09، RF-11، BM-06، CO-06/09: سنجش سرعت، کیفیت فارسی، ablation، goodput، ظرفیت واقعی و مقایسهٔ اقتصادیِ هم‌کیفیت، به اجرای مدل و دادهٔ آزمون احتیاج دارند. نتیجه‌ای برایشان ساخته نشده است.
- HW-06 و HW-14: کنترل ذخیرهٔ دلخواه و فرمول‌های حافظهٔ معماری‌های جدید، توسعهٔ بعدی‌اند. مدل‌های بدون فرمول معتبر در نمای «اندازهٔ وزن» دیده می‌شوند؛ فرمول dense KV به attention ترکیبی تعمیم داده نشده است.
- بخش تکمیلی CAT-04 و RF-05، RF-09 و SC-10: گسترش بیشتر خانواده‌ها، بستهٔ دادهٔ تمرینی و راهنمای اتصال IDE، پیشنهاد محتوای جدیدند و در این نوبت اجرا نشدند.
- SW-09: مستندات اجرای محلی با آزمون عملی قطع اینترنت برابر نیست؛ موارد فاقد آزمون همچنان نامعلوم‌اند.
- CO-01/02: ادعای اختصاصی خدمت ترگمان قبلاً با درخواست صریح صاحب سایت و انتساب به شرکت وارد شده است. ممیزی حاضر سند مستقلی برای انحصار بازار یا جزئیات جداسازی حافظه/خرابی ارائه نمی‌کند؛ معماری، SLA یا مدل جداسازی از روی نام GPU Sharing حدس زده نشد.
- CO-04/07/08: مقایسهٔ کامل API ایرانیِ همان مدل، رفتار cache/batch و شرایط تجاری به تعرفه و شروط قابل تأیید نیاز دارد. تعرفهٔ پیشنهادی گزارش به‌دلیل در دسترس نبودن تأیید مستقیم، به دادهٔ قطعی اضافه نشد.
- HW-12، SC-13، RF-12، CO-10/11 و BM-04 پیشنهادهای گسترده‌تر تحریری/طبقه‌بندی‌اند. اصلاحات اختصاصی و حذف تکرار جدول‌ها انجام شد؛ ادعای بازنویسی کامل همهٔ مقاله‌ها یا اجرای همهٔ پیشنهادهای گزارش نداریم.

## بررسی خروجی

- `npm run check`: بدون خطا و هشدار.
- `npm run verify:llm`: انتساب منابع، هویت ردیف‌ها، مجموع فایل‌ها و وابستگی‌های بازبینی‌شده معتبرند؛ ۹۵ مدل، ۱۶ نرم‌افزار و ۲۴ ردیف تخصصی.
- `node --test tests/llm*.test.mjs`: همهٔ پنج فایل آزمون LLM پاس شدند؛ شامل کنترل‌های منفی manifest و رگرسیون‌های این ممیزی.
- مرورگر محلی: پنهان‌بودن راهنما بدون پارامتر پیش‌نمایش، ردیف‌های Tooka و لوگوی محلی، MoE/پارامتر فعال Qwen، امتیاز MIRACL، وضعیت بایگانی TGI و ابزار تازه بررسی شدند. در عرض ۱۶۰۰ و ۳۹۰، تم روشن و تیره، سرریز افقی صفحه و خطای JavaScript مشاهده نشد. تصاویر و گزارش در `docs/reviews/local-2026-09-16/llm-audit/` هستند.
- اجرای عمومی `npm run test`: ۱۵۷ آزمون پاس و سه شکست قدیمی. دو آزمون GPU هر حرف فارسی در Markdown انگلیسی/اسپانیایی را رد می‌کنند، حتی fragment فارسیِ لینک گزارش ترگمان؛ آزمون مقاله‌ها نیز ارجاع صریح نسخهٔ انگلیسی به گزارش فارسی را رد می‌کند. فایل‌های آن مقاله‌ها و آن دو فایل آزمون نسبت به HEAD تغییر نکرده‌اند. این محدودیت‌های قدیمی آزمون با تغییر محتوا یا حذف ارجاع دور زده نشدند.

تغییرات GPU که پیش از شروع اعمال ممیزی در محیط محلی وجود داشتند، حفظ شده‌اند. این نوبت هیچ commit، push یا deploy انجام نشد.

`npm run build` نیز موفق بود: نقشهٔ سایت با ۱۸۶ صفحهٔ قابل نمایه‌سازی، ۱۹۶ بلوک JSON-LD و ۲۲۱ مقصد لینک کوتاه اعتبارسنجی شد. نمایش عدد اصلاح‌شدهٔ **۲۲٫۴۹ GiB** برای Coder-32B-Q4 در خود مرورگر نیز تأیید شد.
