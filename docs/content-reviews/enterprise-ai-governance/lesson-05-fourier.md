# Lesson 05: reframing and Fourier illustration

The slide uses `لاینحل` for Wicked. The lesson explains that `درهم‌تنیده`
describes that same category, then presents reframing toward an at-least
ill-defined but investigable problem as a teaching goal, without promising
universal reduction of stakeholder conflicts.

The original slide is unchanged. The additional, ignored media source is
`content/articles/fa/enterprise-ai-governance-problem-framing/images/fourier-reframing.svg`.
It is a self-contained, original vector diagram, sampled at 1001 equally spaced
points over `[0, 2π]`:

- Composite: `sin(t) + 0.5*sin(3*t) + 0.25*sin(7*t)`.
- Components: `sin(t)`, `0.5*sin(3*t)`, `0.25*sin(7*t)`.
- All four plots use the same horizontal range and amplitude scale.

The three-component equality is exact for this constructed example. The prose
distinguishes that example from approximating a general periodic waveform with
its main components. The analogy teaches a change of representation; it does
not assert linear superposition of organizational problems.
