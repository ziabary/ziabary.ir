# بازبینی انتشار عامل‌های خودکار و اختیار محدود

بازبینی: ۱۹ سپتامبر ۲۰۲۶. تاریخ انتشار به درخواست نویسنده: ۱۸ سپتامبر ۲۰۲۶ / ۲۷ شهریور ۱۴۰۵.

- مقالهٔ فارسی با `draft: false` و تصویر محلی WebP؛ فایل PNG اصلی حفظ شد.
- تصویر تکراری داخل متن حذف شد؛ قالب مقاله و فصل مجموعه، کاور را نمایش می‌دهند.
- ترتیب دستی مجموعه: دسترسی غیرمستقیم ← مهندسی بدون مشاهدهٔ داده ← اختیار محدود عامل‌ها. نسخه‌های زبانی دیگر تغییر نکردند.
- سه رابطهٔ پیشنهادی نویسنده حفظ شد. پیوندهای درون متن به دستیار اسناد سازمانی، تفاوت دستیار و عامل برنامه‌نویسی، و امنیت کرنل و GPU اضافه شد. هر شش مقالهٔ مقصد منتشرشده‌اند و تاریخشان قبل از ۱۸ سپتامبر است؛ به مقاله‌های قدیمی ارجاع معکوس افزوده نشد.
- بخش پایانی تکراری مسیر مطالعه حذف شد؛ پیوند مجموعه در مقدمه و مقاله‌های مرتبط در متن و فراداده قرار دارند.
- عبارت Azure دربارهٔ تأخیر به سازوکار مشخص تطبیق مجوز با فرادادهٔ نمایه و لزوم همگام‌سازی آن اصلاح شد. تاریخ بررسی قبلیِ داخل متن به‌عنوان بررسی این انتشار بازاستفاده نشد.
- سناریوی تعمیرات همچنان صریحاً فرضی است؛ مقاله گزارش اجرای محصول یا تضمین امنیت نیست.

## نتیجهٔ کنترل محلی

- `npm run check`: صفر خطا و هشدار.
- آزمون موجود `tests/ztai-locales.test.mjs`: موفق.
- `npm run build`: موفق؛ ۱۸۷ صفحهٔ قابل نمایه‌سازی، ۲۱۹ صفحه با دادهٔ ساخت‌یافته و ۲۲۴ مقصد لینک کوتاه اعتبارسنجی شدند.
- مرورگر: تاریخ در دادهٔ ساخت‌یافته، بارگذاری کاور، پنج پیوند درون متن و نبود تصویر تکراری در متن کنترل شد. پیش‌نمایش تصویر در پنجرهٔ اشتراک‌گذاری مستقل از تصویر مقاله است.
- مجموعهٔ فارسی هفت فصل دارد؛ لینک مستقیم فصل جدید آن را باز می‌کند و فصل مهندسی قبل از آن قرار دارد. مقاله و مجموعه در عرض ۳۹۰ پیکسل اسکرول افقی صفحه ندارند.
- فقط نسخهٔ محلی آماده شد؛ انتشار روی سرور انجام نشد.
