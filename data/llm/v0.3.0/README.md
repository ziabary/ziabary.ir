# داده‌های راهنمای LLM، نسخهٔ ۰٫۳٫۰

این نسخه در ۲۰۲۶/۰۹/۱۵ با وضعیت محلی پروژه ادغام شد. منبع دادهٔ پایه `repository.json` است؛ ماژول‌های TypeScript در `src/lib/llm/data/` از همین فایل ساخته می‌شوند. پسوند `.v1.ts` برای سازگاری مسیر importها حفظ شده و نشان‌دهندهٔ نسخهٔ محتوای داده نیست.

دادهٔ نهایی از پایهٔ ۰٫۳ و مکمل موجود `data/llm/v0.2.0/data/` تشکیل می‌شود: ۸۷ مدل، ۴۷۵ بستهٔ دریافت و ۱۱۰۱ نتیجهٔ کیفیت برای ۸۵ مدل. پایه به‌تنهایی ۱۰۷۰ نتیجه دارد. فایل‌های `planning-artifacts.json` و `planning-sources.json` ورودی‌های برآورد حافظه‌اند. در ادغام اولیه، هش هر ۲۵ فایل مکمل با بستهٔ ارسالی یکسان بود. سپس به درخواست صاحب سایت، سه فایل نرخ اجاره، سناریوهای اقتصادی و مثال‌های هزینهٔ توکن حذف شدند. اکنون ۲۲ فایل مکمل وابسته باقی مانده‌اند؛ از فهرست منابع نیز شاهد اختصاصی قیمت RunPod حذف و هش آن به‌روزرسانی شده است. داده‌های حافظه و کارایی بدون تغییر حفظ شدند؛ منبع Trooper فقط برای مشخصات حافظهٔ ۴۰۹۰ اصلاح‌شده باقی مانده است.

پس از ویرایش دادهٔ پایه، از ریشهٔ پروژه اجرا کنید:

```bash
npm run generate:llm
npm run verify:llm
npm test
npm run check
npm run build
```

اعتبارسنجی، تطابق JSON با ماژول‌های تولیدشده، ارجاع شناسه‌ها و شواهد، ادعاها، بسته‌های دریافت و وابستگی‌های مکمل را کنترل می‌کند. `generate:llm` دادهٔ تحقیقاتی جدید گردآوری نمی‌کند.

سه ادعای قدیمی دربارهٔ اجرای آفلاین vLLM، SGLang و llama.cpp در بستهٔ ورودی با فیلدهای صریحاً نامعلوم همان نرم‌افزارها تناقض داشتند. فقط آن سه ادعای مثبت حذف شدند؛ مقدار نامعلوم و منابع باقی ماندند. رکوردهای حذف‌شده و دلیل اصلاح در [integration-corrections.json](research/integration-corrections.json) نگهداری شده‌اند. در زمان ادغام اولیه، خروجی یکپارچه با مرجع ارسالی، به‌جز همین سه رکورد، یکسان بود.

در بازبینی تحریریِ ۲۰۲۶/۰۹/۱۵، ارجاع‌های بدیهی به «کارت رسمی»، توضیح‌های تکراری دانلود و راه‌اندازی و یادداشت‌های فاقد اطلاعات حذف یا کوتاه شدند. عددها، نشانی‌ها، نسخه‌های دقیق، فرمان‌ها و هر ۲۲۸۰ رکورد منبع حفظ شدند. ۹ ادعای متنی که فقط رعایت مجوز را یادآوری می‌کردند حذف و در [editorial-corrections.json](research/editorial-corrections.json) بایگانی شدند؛ وضعیت استفادهٔ تجاری و خود مجوزها تغییر نکرد. متن‌های اختیاریِ راه‌اندازی و زبان در صورت نبود اطلاعات حذف می‌شوند، اما نام موتور، پیوند و شاهد مسیر همچنان الزامی‌اند. شرط‌های مشترک اجرا با ذکر موتورهای مربوط، یک‌بار نمایش داده می‌شوند. [گزارش بازبینی متن و تصویر](../../../docs/reviews/local-2026-09-15/llm-editorial/review.fa.md) شامل نتیجهٔ آزمون‌هاست.

[گزارش ممیزی](research/AUDIT_FA.md)، پوشش مدل‌ها و گزارش منابع در `research/` از بستهٔ ارسالی نگهداری شده‌اند؛ آمار دریافت اینترنتی آن گزارش، نتیجهٔ گردآوری سازندهٔ بسته است. [منشأ لوگوهای محلی](research/local-brand-assets.json) و [گزارش ادغام و آزمون‌های همین پروژه](../../../docs/reviews/local-2026-09-15/llm-v03/review.fa.md) جدا ثبت شده‌اند.

