**بستهٔ نخست داده‌های راهنمای LLM — ۰٫۱٫۰**

این بسته به schema واقعی پروژهٔ ارسالی متصل می‌شود. تاریخ منابع: ۲۰۲۶/۰۹/۱۵. محتوا برای پیش‌نویس است؛ هیچ انتشار یا آزمون اجرای مدل انجام نشده است.

- ابتدا `docs/DATASET-REVIEW.fa.md` را بخوانید: پوشش، یافته‌ها و دو اصلاح لازم رابط.
- فایل `docs/IMPORT-CODEX.fa.md` دستور کامل ورود داده و گزارش‌گیری از Codex است.
- `data/repository.v1.json` دادهٔ اصلی قابل ویرایش است. `src/lib/llm/data/repository.v1.ts` ورودی typed آن است.
- فایل‌های CSV برای مرور مدل‌ها، انتشار نرم‌افزارها، ماتریس قابلیت‌ها و شواهد هستند. مقدار خالی همراه ستون state تفسیر شود.
- `research/` شامل اندازهٔ فایل‌ها، مشاهدات config، گونه‌های کوانتیزهٔ نیازمند تکمیل منشأ، نمره‌های ناشر و محاسبه‌های آموزشی حجم وزن است؛ این داده‌ها خودکار وارد جداول امکان اجرا یا اقتصاد نمی‌شوند.
- `validation/checks.json` نتیجهٔ کنترل واقعی داده و adapterهاست؛ build کامل سایت و benchmark سخت‌افزار را پوشش نمی‌دهد.

بسته شامل ۵۹ مدل، ۵۹ artifact رسمی، ۱۳ انتشار نرم‌افزار، ۷۴ ادعای قابلیت مشروط، ۱۶ رکورد API، ۹ مدل تخصصی و ۵۳۱ رکورد شاهد با ۲۲۱ نشانی منبع یکتا است. چهار جدول شناسنامه، کاربرد کاندید، نرم‌افزار و مدل تخصصی داده می‌گیرند. چهار جدول سخت‌افزار، سازگاری deployment، بنچمارک و اقتصاد هنوز شاهد کافی برای نتیجهٔ مقایسه ندارند.

برای ورود، از اسکریپت guarded یا `integration.patch` طبق راهنمای Codex استفاده کنید. متن مقاله‌ها و gate دقیق `show-drafts=true` در این بسته تغییر نمی‌کنند. دو اصلاح نمایش URL منبع و noteها در راهنمای Codex الزام شده‌اند؛ patch ورود داده به‌تنهایی آن‌ها را انجام نمی‌دهد.

برای نگهداری بعدی: JSON را اصلاح کنید، `python scripts/generate-typescript.py` را اجرا کنید و سپس validator را دوباره اجرا کنید. نسخه، تاریخ، CSVها و گزارش پوشش نیز باید با snapshot جدید هماهنگ شوند. JSON و فایل TypeScript را مستقل از هم ویرایش نکنید.

اسکریپت‌ها وابستگی تازه‌ای به runtime سایت اضافه نمی‌کنند؛ validator از TypeScript موجود در devDependencies پروژه استفاده می‌کند. مقادیر منبع و نمرات، گزارش ناشر یا محاسبهٔ مشخص‌اند؛ هیچ ادعای تأیید مستقل کیفیت فارسی یا توصیهٔ قطعی خرید از این بسته استخراج نشود.
